# clpi/manus

Artifacts from a Manus agent session
([share](https://manus.im/share/cbucYUTkWGxdmjuZ1yUxgb), 2026-09-16
03:19–08:39 UTC, 52 messages, 249 events) in which the user asked for a
from-scratch, graph-native, self-hosted compiler ("Idolic") built from
machine code, with the same brief previously run through Meta AI, Grok,
Devin, and Amp.

What the session built:

- An **Idolic graph-native self-hosted compiler vertical slice in
  JavaScript** (`artifacts/` files under the original `home/ubuntu/idolic/`
  sandbox paths): lexer/parser producing a semantic graph, checker,
  native x86-64 emitter, optimizer, and test/bench scaffolding.
- A **hand-authored x86-64 ELF exit seed** (`bootstrap/idolic-seed`,
  `bootstrap/seed`): raw machine-code bootstrap track intended to
  remove JavaScript from the final repository.
- Design docs: the user's "Idolic Actionable Master Prompt" uploads
  and a 2026-09-15 vertical-slice plan.

The Manus agent's own session notes record that it was pushing toward
`clpi/manus` but never completed the push; this repo preserves the
session as extracted, without completing work the agent itself declined
to claim as complete.

## Layout

- `artifacts/` — all 28 downloaded sandbox files, filenames derived
  from original sandbox path + snapshot timestamp (duplicates
  preserved, e.g. two `README` and two `bin/idolic` snapshots).
- `conversation.md` — the 52-message transcript (verbatim text).
- `manifest.json` — extraction manifest: share metadata, per-file
  SHA-256, byte sizes, and notes.
