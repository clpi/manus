# GAP-146 — build gate reports success after failed child process

**Status:** IN_PROGRESS · **Filed:** !2026-08-10T12:08:03Z
**Priority:** P0 · **Kind:** regression
**Filed by:** codex-root-audit-20260810
**Files:** lib/proc.id,gaps/GAP-115.md

At the audited revision, `duo_build_run(gate=unit-test)` returned
`{passed:true, exit_code:0}` while the same locked invocation output said maker
exited 1 and reported seven failures. The former reproduction endpoint was
`tools/mcp/bench.id`; it is now deleted and must not be restored. Gate truth is
still not bound to child process status until the graph-owned execution outcome
closes. Repair must make structured status reflect the actual completed child
result and add a negative control that runs a known failing child. Do not infer
success from transport/server exit.

The faulty MCP endpoint was deleted on 2026-08-17. The broader obligation
remains open for the graph-owned execution outcome; no new text wrapper replaces
the removed endpoint.

**2026-09-01 progress (devin):** Added negative control to `lib/process.id` that
verifies the actual status code from a failing child process (`false` must exit
with status 1). Updated `lib/proc.id` to return structured status
`{ status: i64 }` for `exec` and `{ output: str, status: i64 }` for `capture`,
ensuring the status reflects the actual completed child result rather than
inferring success from transport/server exit. The `capture` implementation now
appends `$?` to the command output and parses the exit code from the final line,
matching the pattern used in `lib/os/process.id`.

**2026-09-02 progress (devin):** Removed non-canonical `@comp.c.emit` directives
from `lib/os/process.id` `env_set` and `env_unset` functions. These violated
closed lexical law (`@comp.*` directives are not lawful Idol source). The
bootstrap-level env manipulation now uses the admitted `env` table directly;
persistence behavior remains bootstrap-defined.

**2026-09-02 landed:** Bootstrap-level canonicality slice landed on origin/main
(commit 1fd1e314, b17c92e0, 2535dc4c). Removed non-canonical `@comp.c.emit` directives
from `lib/os/process.id` `env_set` and `env_unset` functions, improving closed lexical
law compliance at the bootstrap level. This bounded slice is complete.
