# GAP-198 — Andorra optimization law

**Status:** OPEN · **Filed:** !2026-08-18T16:45:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/optimizer.id

Defer nondeterministic choices until deterministic semantic refinement is
exhausted. Never branch the realization/search state while a deterministic fact
propagation can still reduce the candidate set. This is stronger than "run cheap
passes first"; it is an invariant over the optimizer search.

## Current measured boundary

The optimizer can explore candidate spaces. It does not explicitly postpone
branching until deterministic propagation saturates.

**Crossed:**

- `demand`, `effect`, `range`, `shape` facts already reduce candidates.
- `FRONTIER.md` records rung priority.

**Still missing:**

- `deterministic` vs `nondeterministic` fact producers.
- Scheduler that runs deterministic rules until saturation before search.
- Representation search: reduce to 2 candidates before exploring them.
- Application overload resolution: use known facts before disjunction.
- Proof search: propagate constraints before case split.

## Required order

1. Define `deterministic` and `nondeterministic` fact-producer classes.
2. Schedule all deterministic rule applications before any search/branch.
3. Implement a `branch only after saturation` gate in the optimizer.
4. Demonstrate reduced branching in representation, overload, and proof search.
5. Measure the search-space contraction.

## Closure acceptance

Close when the optimizer can prove it only branches after deterministic
semantic refinement has reached a local fixed point.
