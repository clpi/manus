# GAP-179 — observer-quotient compilation

**Status:** OPEN · **Filed:** !2026-08-18T15:10:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/demand.id, src/obseq.zig

Promote demand from "is this value used?" to "which distinctions can the
admitted observer detect?" Compile only enough computation to preserve those
equivalence classes. This generalizes DCE, partial-result demand, low-bit
quotienting, approximate computing, privacy, aggregate-only queries,
header-only decoding, and theorem-answer elimination.

## Current measured boundary

The periodicity/quotient work already collapses exact state spaces by demanded
bit/field observability. It is not yet a universal compiler phase that decides
legality by observer equivalence classes.

**Crossed:**

- `demand` facts exist and drive elimination.
- Local quotienting demonstrates the power of observation-constrained search.

**Still missing:**

- A canonical `observer` and `observer quotient` model.
- `legal(candidate)` defined as `Q(original) = Q(candidate)` for the demanded
  quotient `Q`.
- Standard observer quotients: sign, low bits, length, parity, membership,
  aggregate, existence, range check, order relation.
- Cross-law application: approximate computing, privacy redaction,
  aggregate queries, theorem-answer.
- Realization search that stops as soon as the quotient is preserved.

## Required order

1. Define `observer` as a semantic entity with admitted distinguishability.
2. Add `quotient` facts to every demanded value: `Q(value)`.
3. Replace DCE and partial-demand with `Q = none` / `Q = exact` extremes.
4. Implement `Q(original) = Q(candidate)` as the legality test.
5. Demonstrate theorem-answer elimination and aggregate-only query compaction.

## Closure acceptance

Close when every elimination of unused computation is justified by an explicit
observer quotient, and when the compiler can stop materializing a value as soon
as the demanded equivalence classes are preserved.
