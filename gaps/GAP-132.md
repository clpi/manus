Release Gate Zero is not closed by commit `1a7924f`. Its `authority(code)`
detector recognizes four literal homes. The exact staged-diff control below was
accepted with zero findings and exit 0:

```duo
script = req "std.script"

```

The same gate rejects the literal `std.script.run(command)`. Canonicality
therefore still changes when a home is aliased or renamed, violating
`law.authority.rename`. This detector remains a useful migration firewall but
must not be reported as SUBJECTGATE, WORLDGATE, or VOCABGATE.

## Adversarial review of the in-flight graph rewrite

The current uncommitted `lib/std/compiler` rewrite is not yet the missing
semantic gate:

1. `parser.app` walks only the first leading token sequence in an isolated
   string. Given a binding followed by an application, it stops at the binding
   and never reaches the application. It cannot resolve an alias to the entity
   it denotes.
2. `foreign.identity` maps the text `getenv` to the hand-authored integer
   `670001`. That is a per-symbol spelling table, not identity resolved from a
   definition, import witness, or canonical relation registry.
3. The foreign row omits descriptor constraints, result cases, realization
   freedoms, ABI, lawset, uncertainty, and provenance. It therefore cannot
   satisfy the public-operation admission contract in C0 section 66.
4. `graph.application` assigns `reachable = 0`, `demand = 1`, and a subject made
   from source coordinates. Required/reachable worlds and demand are not graph
   facts, and the subject is not a semantic value identity.
5. `foreign.native` is always false. No public standard export is inventoried or
   admitted, so `graph.vocabulary` proves no property of the standard surface.
6. The proof passes three isolated spellings of one hard-coded foreign name. It
   never exercises a real standard definition, import alias, staged diff,
   generated source, or whole program. It is not wired into precommit.
7. The rewrite replaces the existing semantic-graph file and SH-07 proof rather
   than preserving their prior reference-graph query under its actual owner.
   Replacing one proof with an unrelated proof destroys evidence instead of
   extending semantic authority.

`timeout 15 ./zig-out/bin/duo run examples/pass16_graph_proof.duo` also exited
124 before producing its claimed pass tuple in this checkout. Compile latency
alone is not the architectural defect, but a release gate must finish and emit a
verdict under its declared budget.

The next dirty iteration wired this hand-authored table into `idiomgate`. The
exact precommit command with an adversarial diff exited 128 after compiling and
emitted neither its positive-control result nor a canonicality verdict:

```text
DUOGATEDIFF=/tmp/rg0-bypass2.diff ./zig-out/bin/duo run scripts/idiomgate.duo
exit 128
last output: ok compile (... ./idiomgate.out)
```

Its table now recognizes the terminal strings `getenv`, `run`, `capture`,
`fs_exists`, and `getenv_or`. This is still bypassable without renaming a home:

```duo
value = safe() + foo.bar.run(command)  -- the one-call reader stops at safe()
go = foo.bar.run
go(command)                            -- the terminal spelling is gone
```

More fundamentally, `std.script` operations are native migration debt, not
foreign symbols. Reclassifying their spellings as foreign provenance gives the
forbidden surface a new authority instead of deriving canonical relations from
definitions.

## Production graph projection evidence

`./zig-out/bin/duo graph lib/std/script.duo` currently emits `sim-v0` nodes and
call-shape rows. A function definition has a stable source identity, while an
application has a different stable site identity plus a `name`, `callee_kind`,
argument count, and call-shape hash. The projection contains no edge from the
application to the definition it resolved, no public-export fact, and no
relation-admission record. It also exposes none of the subject, world, effect,
case, lawset, provenance, or realization-freedom facts required below.

An internal `.use` edge is not yet that proof. `do_graph` retains `Sema` in its
parsed-module result but calls `liftModuleWithCalls` with only the AST. Graph
lift infers a call shape from syntax and reconstructs the target through
`findFunc(callee_name)`. Serializing this edge would therefore expose another
name lookup, not the resolver's authoritative definition identity.

Consequently neither the terminal `name` nor `call_shape_id` may be used as the
registry key. The first production slice must preserve the resolver's callee
definition identity into the graph projection and attach admission facts to
that same identity. Otherwise aliases and renamed operations remain
indistinguishable from unrelated definitions with the same spelling.

## Required closure

1. Derive one registry of public standard definitions. Each callable row carries
   canonical relation identity, subject role, subject-callability, descriptor
   constraints, required worlds, effects, result cases, realization freedoms,
   foreign provenance, and admission state.
2. Reject every newly reachable public standard callable lacking an admitted
   row. Existing unregistered exports remain counted migration debt; new debt is
   fatal.
3. Enumerate applications from the production parsed module and resolve bindings
   before canonicality. Do not add another one-expression parser or a spelling
   table beside the compiler graph.
4. Feed WORLDGATE and SUBJECTGATE actual semantic value IDs and required/reachable
   world edges. Homes contribute only provenance.
5. Positive-control all of these forms against the same relation identity and
   verdict: direct home, import alias, callable alias, arbitrary renamed home,
   alternate operation spelling bound to the same definition, generated source,
   and a valid subject-first application with its required world reachable.
   Also prove that an unrelated admitted relation with the same terminal spelling
   does not inherit the finding.
6. Preserve foreign symbol identity as provenance; require an equivalence witness
   before mapping it to native vocabulary.
7. Emit the structured finding from the shared graph service, then make the same
   nonzero verdict reachable from CLI, LSP, MCP, precommit, and CI.
8. Preserve existing graph queries and their proofs under their semantic owners.
   A new canonicality query is additive until it can replace the same meaning.

Until all eight hold, GAP-124 remains `SEMANTIC-VOCABULARY-BLOCKED`, the staged
text detector remains only a migration firewall, and broader autonomous feature
work must not use an RG0-closed claim.
