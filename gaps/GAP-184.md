# GAP-184 — representation-theorem FFI

**Status:** OPEN · **Filed:** !2026-08-18T15:45:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/foreign_ffi.id, src/representation.md

Replace hand-written foreign-ABI adapters with representation theorems. A
foreign value is admissible in Idol when there exist `Rep_A(v, bytes)` and
`Rep_B(v, bytes)` for the same logical `v` and the same physical bytes. If the
same bytes satisfy both laws, the adapter and copy are zero.

## Current measured boundary

Foreign adapters are implemented per boundary. There is no general
representation-compatibility proof that lets the compiler delete an adapter.

**Crossed:**

- `representation` is a recognized semantic dimension in C0.
- `law.bridge` and `law.foreign` exist.

**Still missing:**

- `Rep(logical, physical)` as a graph fact over every semantic value.
- `compatible(A, B)` theorem derived from `Rep_A` and `Rep_B`.
- Automatic zero-copy when both laws accept the same physical bytes.
- Generalization beyond handcrafted pairs (e.g., Arrow/NumPy).
- Validation of representation invariants for target and foreign law.

## Required order

1. Define `Rep(logical_value, physical_state)` as a relation in C0.
2. Add representation facts for common Idol descriptors and foreign layouts.
3. Implement a representation-compatibility prover.
4. Delete lift/lower/copy when the theorem holds.
5. Generate the adapter only when the theorem fails.

## Closure acceptance

Close when an arbitrary foreign boundary can be proven zero-copy by a
representation theorem, and the compiler falls back to an adapter only when no
proof exists.

## C0 alignment

Instance of the schema in `gaps/RESEARCH-SPINE.md`; `tools/node/dev/gapc0` fails
closed without it.

- **constitutional owners:** relation (`Rep_A`, `Rep_B` are relations) · witness · lifetime · capability · realization
- **kind delta:** 0
- **registry delta:** 0
- **source syntax delta:** 0
- **semantic invariant:** `Rep(logical_value, physical_state)` as relation facts over every semantic value; compatibility requires semantic equivalence ∧ representation ∧ lifetime ∧ authority ∧ effect/failure compatibility — same bytes under different ownership/authority laws still forbid zero-copy.
- **physical mechanism:** representation-compatibility prover; adapter generation only when the theorem fails.
- **prerequisites:** GAP-178.
- **foreign implication:** the universal boundary model — FFI, serialization, marshalling, and layout adaptation are all representation relations over Idol↔C/Rust/Lua/Python/Wasm/WIT/Arrow/NumPy, CPU↔GPU, process↔process, network, storage.
- **world implication:** the same byte buffer can be borrowed, owned, uniquely mutable, shared mutable, foreign-GC rooted, GPU resident, or sandbox-owned without changing its bytes — world facts decide.
- **projection implication:** view-only, repack, copy, and serialize are projection/representation decisions, not conversion taxonomy.
- **demand implication:** the downstream quotient bounds what a foreign boundary must reconstruct.
- **realization implication:** adapter ∈ {zero, view-only, repack-only, copy, serialize} chosen by theorem — the usual FFI/serialization/marshalling distinction collapses.
- **evidence:** one arbitrary boundary proven zero-copy; measured adapter deletion; fallback adapter emitted when unproven.
- **deletion witness:** hand-written per-boundary adapters, lift/lower plumbing, marshalling libraries as separate mechanisms.
