| Measured at HEAD |

| # | directive |
|---|---|
| 1 | node storage std.ArrayListUnmanaged(Node) side hash maps in semantic_graph.zig 16 array/list decls 78 MultiArrayList anywhere in src 0 |

| # | directive |
|---|---|
| 1 | The failure mode usually feared — millions of individually heap-allocated polymorphic nodes behind a generic graph-database API — DOES NOT EXIST here. |
| 2 | Nodes live in one contiguous `ArrayListUnmanaged(Node)` and queries are direct field access. |
| 3 | That part is already right. |

| # | directive |
|---|---|
| 1 | What is absent is the split between hot semantic columns and cold provenance/evidence columns. `Node` is one struct carrying every field any consumer might want, so a query that needs one discriminator drags provenance, origin and quote fields through cache with it. |
| 2 | Every fact family added to `Node` widens the stride of every unrelated traversal. |

| section |
|---|---|
| Why this is filed now rather than when it hurts |

| # | directive |
|---|---|
| 1 | The cost is invisible in current measurements because the corpus is small (78470 nodes over 809 modules). |
| 2 | It is not invisible in a self-hosted compiler: compiler B executes these traversals on every compile, and a graph that is semantically rich but physically wide loses compile-time performance to conventional compilers that carry less information. |

| # | directive |
|---|---|
| 1 | The stated thesis is one semantic graph as authority with many specialized physical views as disposable execution structures. |
| 2 | Columnar storage is a physical view of the same authority — it mints no second semantic store and needs no deletion witness, because nothing reads it as truth. |

| section |

| # | directive |
|---|---|
| 1 | The transfer above had a stale-negative hole: both consumers compared the authority kind only on candidates the column itself nominated, so an authority kind mutating INTO the requested kind after the column was derived was skipped silently — `countOfKind` returned the undercount and `findUnique` answered a false negative instead of refusing. |
| 2 | Measured RED against those tip consumers: the control failed with `expected error.StaleColumn, found 5716` — the silent undercount itself. |

| # | directive |
|---|---|

| 2 | Any authority kind diverging from the recorded kind refuses `ColumnError.StaleColumn`, so freshness is bound to the authoritative node kinds, not only to the column self-checksum. |
| 3 | The error set of both consumers is `Allocator.Error!ColumnError`, so a wrong-error refusal cannot type-check. |
