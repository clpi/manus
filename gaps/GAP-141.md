# GAP-141 - generated runtime reserves a different temporary path than it uses

**Status:** OPEN · **Filed:** !2026-08-10 · **Priority:** P0 · **Kind:** security

## Observed defect

| # | directive |
|---|---|
| 1 | `src/codegen.zig` emits `duo_make_temp_path`, which calls `mkstemp` for `/tmp/duo_ldXXXXXX`, closes and unlinks that file, then appends the requested suffix. |
| 2 | The returned `.err`, dynamic-library, or `.lua` path was never created atomically. |
| 3 | A local process can occupy or redirect that final path before the generated runtime writes or invokes it. |

| # | directive |
|---|---|
| 1 | The defect remains in current `main` at the filing point. |
| 2 | Unmerged commit `d6a1995` identified the same failure and switched the final path to `mkstemps`, but its June branch predates the current constitution and must not be merged wholesale. |

## Required repair

| # | directive |
|---|---|
| 1 | Reserve the exact suffixed path atomically and retain ownership until its consumer opens it. |
| 2 | The bootstrap compatibility runtime may use the smallest local `mkstemps` bridge, including a fail-closed WASI projection, only while the generated C runtime owns this behavior. |
| 3 | The deletion trigger is the Idol world-backed artifact/process realization replacing `duo_make_temp_path`. |

| # | directive |
|---|---|
| 1 | Do not introduce a public `std.script`, filesystem, process, or temporary-path relation to hide the bridge. |
| 2 | Namespace reachability grants no authority. |

## Acceptance

1. A positive control demonstrates that the current helper reserves only the
   unsuffixed path and leaves the returned suffixed path absent.
2. The repaired helper atomically creates the exact returned path.
3. Error capture, dynamic-library emission, and source loading still work.
4. WASI fails closed rather than returning an unreserved path.
5. The test consumes a private per-run directory and cannot overwrite another
   session's evidence.

| 1 | On current `27e3d24` plus the owned `src/codegen.zig` worktree change: |

  crashed;

  `aarch64-macos`, `x86_64-windows-gnu`, and `wasm32-wasi`.
