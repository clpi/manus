# GAP-145 — lexical authority is not projected into distinct canonical token identities

**Status:** OPEN · **Filed:** !2026-08-10T12:08:08Z
**Priority:** P0 · **Kind:** expressiveness_gap
**Filed by:** codex-root-lexical-20260810
**Files:** docs/spec/constitution.duo,docs/spec/grammar.md,AGENTS.md,CLAUDE.md,lib/std/compiler/token.duo,lib/std/compiler/lexer.duo

Implement STRING-ONE, BYTES-ONE, COMMENT-ONE, reserved backtick, compatibility
provenance, generated grammar roles, and derived tooling projections in
migration order without text reconstruction.

## Current measured boundary

The ruling is now encoded in C0, the normative grammar projection, and the agent
preflight. The operative `CLAUDE.md` projection is separately claimed and was
not edited. Documentation is authority, not implementation closure.

The live compiler contradicts the ruling at the first token boundary:

- `lib/std/compiler/token.duo` exposes one `KIND_STRING_LIT`;
- `lib/std/compiler/lexer.duo` sends quote bytes 39 and 34 through one
  `read_str` path and emits that same identity;
- the Duon lexer also emits the same identity for Lua long strings;
- `src/lexer.zig` mirrors the collapse as `.string_lit`;
- both lexers tokenize `#` and `##` as prefix operators;
- both lexers retain Lua dash/long comments as their ordinary comment path;
- backtick already has a token and host parser consumers despite having no
  admitted canonical value;
- `src/parser.zig` reconstructs long-string delimiter spans from source after
  lexing; and
- Tree-sitter contains independent quote, long-string, comment, and hash-length
  productions.

The current production Duon lexer is an executed SHC authority for token
content and spans. Changing only the host lexer would therefore regress SHC;
changing only the Duon lexer would break its differential and generated C
projection. The split must land as one lexical identity transfer.

## Required order

1. Add distinct Duon-owned token identities and compatibility/lawset status for
   text, bytes, Lua long text, canonical comment, Lua comments, shebang, and
   reserved backtick.
2. Generate compact grammar roles from the constitutional grammar owner. Parser
   consumers must use identities/roles, never delimiter text.
3. Add canonical and compatibility lexer differentials, including unchanged
   spelling with changed identity and changed spelling with preserved role.
4. Implement canonical multiline text normalization exactly once: omit the
   opening and closing structural newlines, remove the closing-delimiter indent
   from every nonblank content line, and diagnose insufficient indentation.
5. Preserve single-quoted Lua text under compatibility provenance and migrate
   it to double-quoted text before native Duon interpretation. Native single
   quotes then produce byte-sequence semantics; Unicode escapes remain rejected
   pending separate admission.
6. Make hash comment-only in canonical Duon and migrate length to the admitted
   subject-oriented `len` relation. Compatibility `#value` remains provenance,
   not a second native relation.
7. Project the same authority into parser, formatter, canonicalizer,
   Tree-sitter, LSP, MCP, generators, documentation, and corpus ratchets.
8. Migrate canonical source only after exact rewrites exist. Never replace
   historical single quotes or long strings textually without a semantic
   equivalence witness.

## Required controls

- Double-quoted text, single-quoted bytes, compatibility single-quoted text,
  and Lua long text have distinct token identity/provenance.
- One-byte demand can scalarize a byte sequence without changing its semantic
  literal identity.
- Canonical hash comments are trivia; canonical `#value` is rejected; Lua hash
  length is compatibility-only and resolves to canonical `len` semantics only
  through a witnessed projection.
- Backtick cannot reach process execution and is rejected in canonical source.
- A byte-zero shebang is distinct from an ordinary hash comment by source
  position fact.
- Parser classification changes with token identity, not delimiter text.
- Removing comments changes only trivia provenance, not semantic graph facts.
- Generators and Tree-sitter consume the authority projection rather than local
  spelling lists.

## Performance and closure

Token role selection must compile to constant-time ID/bitset or equivalent
lookup. Text and byte payloads retain source spans/views where lawful; multiline
normalization must not force an intermediate allocation when indentation
metadata suffices. Record parse latency, copied bytes, and allocations across
the production lexer differential.

Close only when all canonical producers and consumers use the generated lexical
authority, the complete classified canonical corpus has zero debt for the six
retired forms, compatibility fixtures preserve their source lawsets, and no
downstream text reconstruction remains. An incomplete grep census cannot claim
zero.
