# GAP-158 — Path names violate LAW-ONE across scripts, lib, and src

## State

Open.

## Problem

C0 (`law.path.name`) says project-controlled semantic paths obey the same
lowercase one-word law as Idol source identifiers and forbids underscores,
compounds, and numeric taxonomy suffixes. Current tracked paths massively
violate this.

81 `.id` files in `scripts/` and `lib/` contain underscores. Many `.zig`
files in `src/` also violate.

## Evidence

```
scripts/abi_matrix.id          → compound: abi + matrix
scripts/bootstrap_scan.id      → compound: bootstrap + scan
scripts/parser_corpus_coverage.id → triple compound
scripts/language_census2.id    → compound + numeric suffix
scripts/duo_idiom_gate.id      → historical name + compound
scripts/run_wasm_benchmark.id  → compound
lib/std/compiler/emit_c.id     → compound
lib/std/compiler/token_view.id → compound
lib/std/ffi_gen.id             → compound
lib/std/fs_watch.id            → compound
lib/std/mem_ring.id            → compound
```

## Classification

| Category | Count | Action |
|---|---|---|
| tool_workflow | 59 | Relocate outside canonical semantic-source teaching space or give one irreducible operational name |
| needs_review | 13 | Audit: semantic home → decompose into real home hierarchy; or tool → relocate |

## Rule

Do NOT merely do `abi_matrix → abimatrix`. That still violates semantic
decomposition. Each path must be classified:

- **semantic home** → decompose into real home hierarchy
- **tool/workflow label** → relocate outside canonical semantic-source
  teaching space or give one irreducible operational name
- **history/bootstrap** → classify mechanically
- **obsolete** → delete

## Enforcement

PATH-ONE must become a real new-path gate, not just constitutional prose.
The existing `gates/path.id` checks added lines but does not prevent new
underscore paths from being created.

## Deletion prerequisite

- Gates must reject new underscore/compound paths at creation time
- Existing debt ratcheted downward via migration ledger
- `.zig` files are foreign realization; path law applies but migration
  priority follows SHC frontier

## Negative control

Create a file `scripts/foo_bar.id` — gate must reject it.
Create a file `scripts/foo.id` — gate must accept it.
