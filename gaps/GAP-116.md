| 1 | The audit's P0 is that realization does not consume authoritative semantic facts. `src/dnir_lower.zig:337` is that architecture in four lines: |

```zig
pub fn lowerModuleWithGraph(alloc, mod, graph: ?*const semantic_graph.SemanticGraph) {
    var m = try lowerModule(alloc, mod);          // AST -> DNIR. graph unused.
    if (graph) |g| try applyGraphToModule(alloc, g, &m);   // graph applied AFTER
    return m;
}
```

| # | directive |
|---|---|
| 1 | **Lowering completes from the AST, and only then is the graph applied to the finished module.** The graph cannot inform lowering because lowering has already happened. |
| 2 | Every reconstruction map in `LowerCtx` follows from this one ordering: the lowerer must re-derive what sema knew, because at the moment it runs there is nothing to ask. |

| # | directive |

| 1 | This is the marker the audit asks for — *"the first commit where this stops being true."* It is a four-line function, and the diff that fixes it will be visible here first. |
