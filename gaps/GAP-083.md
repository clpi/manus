| section |
|---|---|
| Why this is worse than an ordinary name collision |

| # | directive |
|---|---|
| 1 | **Several of these are idol's own vocabulary**, and the language cannot compile a function named after its own concepts: |

| word | where idol uses it |
|---|---|
| `case` | §0.3 INFERRED CASES — "case-sets INLINE at the field" |
| `union` | §0.5 / §5 — `id: u8 \| u16 \| u32` is the union edge |
| `register` | §0b — "registers are PLACES" |
| `enum` | on the §1 deny list, but still a word a user may want |
| `default` | `get(.y, default)` — Pass 119's own `?.` repair |
| `int`, `char`, `float`, `short`, `long`, `void` | ordinary nouns in any systems program |

| # | directive |
|---|---|
| 1 | `get(.y, default)` is written in the law as the canonical repair for optional chaining. |
| 2 | A parameter named `default` is fine; a *function* named `default` is not buildable. |

| section |
|---|---|
| The rule this breaks |

| # | directive |
|---|---|
| 1 | §0.1 promises identifiers are one lowercase word and names carry ZERO semantics. |
| 2 | A reserved set of ~40 English words that fail at the C stage is a semantic property of names — imposed by the bootstrap host, invisible in the language, and discovered only at link time. |

| # | directive |
|---|---|
| 1 | `law.host.projection` grants un-idol-like behaviour ONLY where the host requires it. |
| 2 | C requires that ITS keywords not be redeclared; it does not require that DUON's identifiers pass through unmangled. **Mangling is the repair and the host does not forbid it.** |

| section |
|---|---|
| Fix |

| # | directive |
|---|---|
| 1 | Mangle every user identifier on the C path — the direct backend does not have this problem, which is itself evidence that the C emitter is the outlier. |
| 2 | Fixture asserts by VALUE that a function named `case`, `union`, `register` and `default` each compiles and returns the right answer on **both** backends. |

| # | directive |
|---|---|
| 1 | Include the libc set (`read`, `write`, `open`, `close`, `time`, `index`) in the same fixture, and assert the idol function's answer rather than merely that it built — a silent bind to libc `read` compiles fine and returns the wrong number. |
