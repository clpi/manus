# GAP-042 — a method declaration disqualifies its whole module from native

**Filed** 2026-08-08. **Status** open. **Cost** 1 program today; the shape is
canonical, so the cost grows as the corpus converges on Pass 100.

## What

`native_scalar_precheck` refuses any module containing a function declaration
whose path is more than one segment (`src/codegen.zig:3177`,
`if (fd.path.len != 1) return nofit(@src())`). A method declaration is exactly
that:

    Person:greet = (other) "Hey " .. other      -- path = { Person, greet }

Isolated to one fact: a file containing only that line plus `main(): i64  0`
bails at codegen.zig:3177. Delete the line and the same file compiles natively.

## Why it surfaced now

`examples/pass23_canonical_syntax.duo` lowered natively earlier tonight and
does not now — native coverage 90 -> 89. The FILE is unchanged since a312382
and the RULE predates tonight, so neither moved.

What moved is the PARSER. That line previously did not reach the precheck as a
`func_decl`; it does now. So this is a parser becoming MORE correct and
surfacing a native-subset limitation that was always there — not a regression
to revert. The honest number is 89.

## Why it matters more than one program

Pass 100 §6 makes the receiver face the canonical call form, and §0 rule 4 puts
construction on descriptors. Method declarations are not a legacy shape the
corpus is migrating away from; they are where it is migrating TO. Every module
that adopts one loses native lowering entirely — the precheck rejects the
MODULE, not the function.

## The repair

`fd.path.len != 1` is a proxy for "this is a method and the native subset has no
receiver ABI". The subset already lowers a receiver face at the CALL site —
`faceAsCall` in dnir_lower normalizes `a:m(x)` to `m(a, x)` — so the missing
half is the DECLARATION: bind `Person:greet = (other)` as a free function whose
first parameter is the receiver, exactly the shape `faceAsCall` already emits
against.

That is the same normalize-at-the-lowering move that made `s[i]` and
`string.char` work: give the backend one convention and translate at the edge.
