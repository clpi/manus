## Exact value-flow source of the loop moves

| # | directive |
|---|---|
| 1 | The `kernel` body is: |

```text
local.get 0; const A; add; local.tee 0
local.get 1; local.tee 3; const B; mul; add; local.set 1
local.get 2; const -9; add; local.tee 2; br_if 0
```

| # | directive |
|---|---|
| 1 | `jit_compile` tracks only `ali_slot` and `ali2_slot`. |
| 2 | Before `local.tee 3`, its generic pre-materialization writes both pending aliases into fixed operand-stack registers, then the `local.tee` arm copies the top stack register into local 3. |
| 3 | At loop termination, `local.tee 2` creates another alias but `br_if` cannot read it; pre-materialization emits a move and the branch reads the stack register. |
| 4 | These are the observed loop-carried copies. |

| # | directive |
|---|---|
| 1 | Adding a third alias channel would preserve the defect. |
| 2 | The required fact is: |

```text
semantic value -> current register(s) -> live uses
```

| # | directive |
|---|---|
| 1 | for every operand-stack value and local. `local.get` projects an existing value, `local.tee` adds a binding/use without changing that value, and `br_if` consumes the value in its current register. |
| 2 | Materialization happens only where liveness requires distinct storage; local 3 genuinely needs the old local-1 value after local 1 is overwritten, while the temporary stack copies do not. |

| # | directive |
|---|---|
| 1 | The same value graph exposes `add(mul(old-local-1, B), new-local-0)` as one `MADD`, and preserves the signed value of `-9` long enough to select `SUB #9` instead of materializing `0xfffffff7`. |
| 2 | Implement this as ordinary Idol value/control/realization facts shared with SHC. |
| 3 | Do not extend the two-slot cache, add a `hot_big` recognizer, or create a Wasm-only opcode/allocator. |

| # | directive |
|---|---|
| 1 | The instruction budget is consequently concrete. |
| 2 | Keep the one required copy that preserves old local 1 in local 3; remove two alias flushes and the final branch-feed move; replace `MUL; ADD` with `MADD`; replace constant materialize plus `ADD` for -9 with `SUB #9`. |
| 3 | The 15-instruction loop becomes approximately 9 instructions, matching the inspected Wasmtime loop. |
| 4 | This is a falsifiable closure target for the shared value/liveness realization, not a benchmark timing guess. |

## 2026-08-10 rejected signed-immediate prototype

|---|---|

| # | directive |
|---|---|
| 1 | The prototype was nevertheless rejected and reverted. |
| 2 | The decoder exposes raw wire bytes and generated `OP_*` constants, not the production relation and descriptor identity declared by the SHC application schema. |
