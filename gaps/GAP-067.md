# GAP-067 — `--backend=direct` DROPS a numeric `for` body whose only effect is a CALL

**Status:** CLOSED 2026-08-09 · **Filed:** 2026-08-08
**Severity:** silent wrong answer on the CANONICAL backend. Exit status 0, `ok
compile`, no diagnostic, no bail. Pass 103 makes `--backend=direct` the path,
so this is wrong output from the shipping backend.

## The defect

```duo
main: i64 = ()
    for i = 1, 3
        print(i)
    0
```

| backend | output |
| --- | --- |
| `--backend=c` | `1 2 3` |
| `--backend=direct` | *(nothing)* |

Both print `ok compile`. Both exit 0.

## Narrowed: the loop is treated as PURE, and a call is not an effect

Probes, `direct` vs `c`:

| probe | direct | c | |
| --- | --- | --- | --- |
| `for i = 1, 3` / `print(i)` | *(empty)* | `1 2 3` | **DIVERGE** |
| `for i = 1, 3, 1` / `print(i)` (explicit step) | *(empty)* | `1 2 3` | **DIVERGE** |
| `for` calling a user fn `side(i)` | *(empty)* | `1 2 3` | **DIVERGE** |
| nested `for` / `for` / `print(j)` | *(empty)* | `1 2 1 2` | **DIVERGE** |
| `for i = 1, 3` / `s += i`, then `print(s)` | `6` | `6` | OK |
| `for i = 1, 3` / `g += i` (file-scope global) | `3` | *(gap[066])* | direct OK |
| `while i <= 3` / `print(i)` / `i += 1` | `1 2 3` | `1 2 3` | OK |

So it is **not** `for` generally and **not** `print` specifically:

- `while` with the identical body is correct — only the numeric-`for` lowering.
- Accumulating into a value the function returns keeps the loop.
- Writing a file-scope global keeps the loop.
- Any CALL as the sole body effect — builtin or user-defined — loses it.

The reading: the numeric-`for` lowering computes body liveness from
*data* reaching an observable, and a call is not counted as an observable
effect. With no live data out of the body, the trip count is folded away.

`xs[i]` reads are incidental — the first reproducer used a table and the table
turned out to be irrelevant.

## Why no gate caught it

`native-differential` compares **exit status only** (see
`duo-backend-divergence-harness`). Every row here exits 0 on both backends and
differs only on stdout, so the harness is structurally unable to see it. That is
the finding behind the finding: **the differential must compare stdout bytes**,
or an entire class of dropped-effect defects is invisible to it.

The `while` row is the positive control — it proves the probe can report
agreement, so the empty `direct` column is a real absence and not a broken
harness.

## Fix

Two parts, and the second is the one that must not be skipped:

1. Numeric-`for` liveness must treat a call in the body as an effect, matching
   whatever the `while` lowering already does correctly — `while` is the working
   reference in-tree.
2. `native-differential` must diff **stdout**, not exit status. Land the four
   DIVERGE rows above as fixtures asserting the printed VALUES.

## Reproducer

`for i = 1, 3` / `print(i)` / `0` — six lines, above.
