*Original filing follows, unamended.*
**Law:** Pass 105 §3 U1 + §4 `std@{ ambient = false }` — effective immediately
**Owner:** `lib/**`

Pass 105 U1 commits to **zero ambient authority in std from the first release**:
fs / net / clock / rand reach programs only through worlds. Java and Node both
tried to retrofit this and both failed, which is why it is on the
unretrofittable list.

This file records the measured distance on the day the scan became law, so the
charter cannot be read as describing a property this repository already has.

## The measurement

`lib/**/*.id`, call-shaped hits only (`name.op(` at a non-comment
position), 2026-08-08:

| reach | sites | files |
|---|---:|---:|
| `os.<op>(` | 140 | 30 |
| `io.<op>(` | 141 | 28 |
| `os.clock` | 53 | 13 |
| `getenv(` | 30 | 10 |
| `fs.<op>(` | 1 | 1 |

**46 of 257 std modules make at least one ambient call — 18%.**

`net.` and `rand(`/`random` are at **zero**, which is worth stating because a
zero on a fresh probe is usually a broken probe: those two are genuinely absent
from `lib/std` rather than unmeasured. The others are not.

## Why the number is not the whole finding

The grep measures REACH, not authority. Some of these are legitimately
world-shaped already and only *look* ambient because the world is threaded
implicitly by the current implementation; others are true ambient authority.
Separating them requires the anchor, not a regex:

```
std@{ ambient = false }
```

which is the instrument Pass 105 §4 actually specifies. Until `@`-anchored
protocol checking runs over std, this grep is a **proxy with a known bias** —
it over-counts world-threaded calls and under-counts authority obtained by
other means (a module that reads a global, or one that reaches the world
through `@c.emit`, is invisible to it).

Two known blind spots, both real in this tree:

* `lib/os.id` and `lib/io.id` obtain their capability through
  `@c.emit` — raw C in the bootstrap ledger. A regex over Duo call syntax
  cannot see that, and those two modules are the root of most of the 46.
* `os.clock` is 53 sites and is the single largest concentration. Clock is on
  U1's list explicitly, and it is also what `zig build bench` and much of
  `scripts/` are built on, so removing ambient clock reach is a change to the
  measurement apparatus as well as to std.

## What must happen, in order

1. **Keep the number visible.** Any std module that gains an ambient call
   raises this count; the count belongs in the claims dashboard (Pass 105 §4,
   `release@published(metrics)`).
2. **Replace the proxy with the anchor.** `std@{ ambient = false }` as a real
   protocol check over the module graph, not a grep. That depends on protocol
   anchoring running over std, which is owed in §22.
3. **Thread worlds where authority is real**, starting with `clock` — the
   largest, the most mechanical, and the one whose removal makes deterministic
   builds (U2) checkable rather than aspirational.

## Honest status of U1

U1 is a **commitment with a measured distance**, not a property held today.
18% of std reaches the world ambiently. The charter says nothing ships with
ambient reach *ever* — that clock starts at the first release, and this file is
the evidence of where the repository stood when the rule was written.

## AMENDED 2026-08-08 — the gate exists, and it corrects three of these numbers

`zig build capability-scan` (`scripts/capability_scan.id`) replaces the one-off
grep above with a ratcheting gate. Measured at `878e0d1` over the same 257
modules:

| class | sites | modules |
|---|---:|---:|
| fs | 58 | 12 |
| net | 9 | 1 |
| clock | 82 | 21 |
| rand | 50 | 14 |
| proc | 77 | 20 |
| fault (abort / exit / kill) | 5 | 5 |
| **union** | **278** | **53 of 257 (20%)** |

Three corrections, and each is the same lesson:

* **`rand` was not zero, it was unmeasured.** This file flags its own zero as
  suspicious ("a zero on a fresh probe is usually a broken probe") and then
  keeps it. It was broken: the probe looked for `rand(` and `random`, and this
  tree spells it `math.random(` — **50 sites in 14 modules**, the third-largest
  class. The suspicion was correct and acting on it was one grep away.
* **`net` was not zero either** — 9 sites in `lib/net.id`, five of them the
  bodyless declarations of `connect` / `listen` / `accept` / `send` / `recv`.
  A free function any caller can reach with no world in hand is ambient
  authority in its strongest form, not its weakest.
* **`abort` / `exit` / `kill` were not a class at all.** They are: a failure
  that unwinds a WORLD is ordinary, and a call that takes the process down
  reaches past every world above it. 5 sites, 5 modules.

The blind spot this file names — capability obtained through `@c.emit`, which
"no regex over Duo call syntax can see" — is now covered: the libc names are in
every class pattern, so the C inside those payloads is counted.

The worst offenders, which is where threading a world buys the most:

Item 2 of the list above is unchanged and is still the real repair: the gate is
a PROXY with a stated bias, and `std@{ ambient = false }` as a protocol check
