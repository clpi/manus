# GAP-182 — runtime guards as semantic experiments

**Status:** OPEN · **Filed:** !2026-08-18T15:35:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/effect.zig, src/deopt.id

Unify inline caches, type guards, branch profiling, shape checks, version checks,
and hardware counters as one mechanism: observe proposition `P` at runtime, refine
semantic knowledge, and unlock a conditional realization. Static proof, profile
evidence, and guarded speculation remain distinct epistemic categories, but the
same graph handles all three.

## Current measured boundary

Guards exist as JIT/deopt machinery in foreign systems. Idol has no unified
runtime-experiment fact family; profile and guard are not first-class semantic
entities.

**Crossed:**

- `law.assumption` and `law.guard` are recognized in C0.
- `deopt` is listed as a research direction.

**Still missing:**

- `experiment(P)` = `{ proposition, evidence kind, cost, conditional theorem }`.
- Runtime facts refine the candidate set: `if P then candidate C is admissible`.
- Distinct epistemic categories: axiom, proven, inferred-sound, guarded,
  profiled, sampled, heuristic.
- Guard invalidation = assumption false ⇒ realization inadmissible.
- Profile evidence does not prove semantics; it is evidence only.
- Hardware counters as a fact-producer.

## Required order

1. Add `experiment` and `guard` as graph facts with provenance.
2. Distinguish semantic probability from compiler epistemic probability.
3. Make a guarded realization admissible only under its stated assumptions.
4. Implement invalidation: assumption becomes false ⇒ candidate ceases to be
   admissible and deoptimization selects another.
5. Treat profiles, samples, and hardware counters as evidence producers,
   not semantic truth.

## Closure acceptance

Close when all runtime specialization (inline caches, type/shape/version guards,
profiling, hardware counters) is modeled as a `guard(P) ⇒ candidate` fact with
explicit invalidation semantics, and when profile evidence can never justify a
semantics-changing optimization without a guard or proof.
