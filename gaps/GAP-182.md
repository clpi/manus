# GAP-182 — runtime guards as semantic experiments

**Status:** OPEN · **Filed:** !2026-08-18T15:35:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/effect.zig, src/semantic_graph.zig, src/assumption_guard.zig, src/gap182_order34.zig, src/main.zig

Unify inline caches, type guards, branch profiling, shape checks, version checks,
and hardware counters as one mechanism: observe proposition `P` at runtime, refine
semantic knowledge, and unlock a conditional realization. Static proof, profile
evidence, and guarded speculation remain distinct epistemic categories, but the
same graph handles all three.

## Current measured boundary

Guards exist as JIT/deopt machinery in foreign systems. Idol has no unified
runtime-experiment fact family; profile and guard are not first-class semantic
entities.

## Closure acceptance

Close when all runtime specialization (inline caches, type/shape/version guards,
profiling, hardware counters) is modeled as a `guard(P) ⇒ candidate` fact with
explicit invalidation semantics, and when profile evidence can never justify a
semantics-changing optimization without a guard or proof.

## C0 alignment

Instance of the schema in `gaps/RESEARCH-SPINE.md`; `tools/node/dev/gapc0` fails
closed without it.

- **constitutional owners:** witness (a guard is a conditional witness) · effect · trust (`guarded` is an existing level in C0 `trust.order`)
- **kind delta:** 0
- **registry delta:** 0
- **source syntax delta:** 0
- **semantic invariant:** `experiment(P)` = proposition + evidence kind + conditional theorem; a guarded realization is admissible only under its stated assumptions; assumption false ⇒ realization inadmissible.
- **physical mechanism:** guard emission and invalidation; deopt selects the next candidate; hardware counters as fact producers.
- **prerequisites:** GAP-181.
- **foreign implication:** foreign runtimes' inline caches and deopt machinery expressed as the same fact family.
- **world implication:** guards are world-qualified evidence; a guard is not "JIT machinery", it is runtime experiment under an effectful relation.
- **projection implication:** none.
- **demand implication:** the conditional theorem is demanded-quotient scoped.
- **realization implication:** static proof, profile evidence, and guarded speculation are epistemic levels of ONE mechanism — one graph handles all three; profile evidence never justifies a semantics-changing optimization without a guard or proof.
- **evidence:** one guarded specialization with measured invalidation and fallback behavior.
- **deletion witness:** JIT guard machinery as a separate subsystem; unlabelled profile-truth.
