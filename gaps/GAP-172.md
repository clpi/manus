```text
                  OR Idol reaches the proven lower bound)
```

| # | directive |

| 1 | Status is a closed enum — **no other value is admissible**: |

| status | meaning |
|---|---|
| `win` | strictly dominates the best competitor, with equivalence + confidence |
| `bound` | equals the proven lower bound (no improvement physically possible) |
| `open` | loses an improvable dimension (carries exact debt row) |
| `unknownbound` | no useful lower bound known — NOT optimal, distinct from `bound` |

| # | directive |
|---|---|
| 1 | Forbidden framings (never statuses, never closure): `averagewin`, `geomeanwin`, `goodenough`, a collapsed scalar, a geometric mean that hides an open loss. |
| 2 | Idol opens a case **automatically** whenever it loses an improvable dimension. |

| section |
|---|---|
| Five graphs carry the frontier (A–E) |

| graph | shape |
|---|---|
| **A observation** | application/use → required observations → producer → proof |
| **B demand** | use → demanded property/portion/quality → upstream transformer |
| **C law** | relation/descriptor → semantic law → witness → implications |
| **D frontier** | region → candidate realization → preconditions → proof → cost vector → dependencies → status |
| **E debt** | region → lower bound → selected realization → delta → cause |

| # | directive |
|---|---|
| 1 | `E.cause` is classified, not prose: `missing-fact` · `missing-demand` · `missing-law` · `missing-candidate` · `missing-search` · `missing-proof` · `wrong-cost-model` · `wrong-placement` · `wrong-algorithm` · `wrong-representation`. |

| section |
|---|---|

```text
measure → find largest weighted debt → classify (E.cause)
        → implement → validate (law.optimization.validated) → ratchet
```
