## Obligation

Stop encoding FTCFTW as an enumerated optimization checklist. Build the
machinery that makes every semantic fact, demand, law, physical alternative,
proof method, and target resource enter **one measurable frontier**, and makes
every uncovered region mechanically visible as **FTCFTW debt**. Individual
optimizations are instances discovered inside the frontier (`law.optimization.open`,
`law.optimization.space`), never constitution additions.

Authority: `docs/spec/law.md` §98–§110 · C0 `law.ftcftw.dominance`,
`law.optimization.open`, `law.cost.closure`, `law.lower.bound`,
`law.optimization.space`, `law.realization.universe`.

## Acceptance contract

```text
FTCFTW(case) = semantics-equivalent
             AND (Idol dominates best-known competitor
                  OR Idol reaches the proven lower bound)
```

Every case persists exactly one row:

```text
subject world target workload observations competitor lowerbound idol
delta cause producer consumer proof evidence status
```

Status is a closed enum — **no other value is admissible**:

| status | meaning |
|---|---|
| `win` | strictly dominates the best competitor, with equivalence + confidence |
| `bound` | equals the proven lower bound (no improvement physically possible) |
| `open` | loses an improvable dimension (carries exact debt row) |
| `unknownbound` | no useful lower bound known — NOT optimal, distinct from `bound` |

Forbidden framings (never statuses, never closure): `averagewin`, `geomeanwin`,
`goodenough`, a collapsed scalar, a geometric mean that hides an open loss.
Idol opens a case **automatically** whenever it loses an improvable dimension.

## Five graphs carry the frontier (A–E)

| graph | shape |
|---|---|
| **A observation** | application/use → required observations → producer → proof |
| **B demand** | use → demanded property/portion/quality → upstream transformer |
| **C law** | relation/descriptor → semantic law → witness → implications |
| **D frontier** | region → candidate realization → preconditions → proof → cost vector → dependencies → status |
| **E debt** | region → lower bound → selected realization → delta → cause |

`E.cause` is classified, not prose: `missing-fact` · `missing-demand` ·
`missing-law` · `missing-candidate` · `missing-search` · `missing-proof` ·
`wrong-cost-model` · `wrong-placement` · `wrong-algorithm` ·
`wrong-representation`.

## Mechanical development loop

```text
measure → find largest weighted debt → classify (E.cause)
        → implement → validate (law.optimization.validated) → ratchet
```

A semantic opportunity with **no candidate provider** is debt made visible
*before* a benchmark regression (search-space gap: e.g. GPU present but no GPU
candidate producer; associativity known but no reduction-search provider; static
keys known but no perfect-hash candidate).

   consumers), queryable by MCP as `observations(id)`,
   `cost_if_observation_removed(id, obs)`, `demand(id)`, `laws(relation)`,
   `frontier(region)`, `debt(region)`.
2. Every measured case persists the acceptance row with a status in
   `{win, bound, open, unknownbound}` and no aggregate hides an open loss
   (FTC-020 gate green).
3. At least one end-to-end loop iteration closes a real debt: a measured `open`
   case (GAP-169 worklist, e.g. direct-backend LICM) becomes `win` or `bound`
   with a validated equivalence proof and a ratcheted historical-best row.
4. Search-space coverage ledger (FTC-017) reports zero silent uncovered semantic
   power for the exercised corpus, or names each uncovered region as debt.
