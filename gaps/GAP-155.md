## Ruling

Host process APIs are not Idol semantics. Arguments, environment, endpoints,
commands, and backend selection are root-projected semantic values observed under
appropriate home/world authority.

Foreign host calls may exist only at the outermost bootstrap ingress boundary
until production root projection executes in the compiler graph.

## Acceptance

1. `docs/spec/host.md` is the authoritative projection; agents route here before
   touching transport, args, environment, process, or shell surfaces.
2. `scripts/ingress/` is the sole bootstrap owner of direct `os.args`, `io.read`,
   and `io.open` for gate transport; gate scripts consume projected values only.
3. `gates/host.id` ratchets zero **new** host API debt on staged **added** lines only.
4. `semanticgate` does **not** host host spelling census — GAP-124 owns semantic verdicts.
5. Production negative controls prove rename-invariant semantics for args,
   environment, command/process world, and shell-home command projection
   (blocked on GAP-124 graph ingestion).
6. No new `std.*`, `core.*`, `process.*`, or spelling-detector kingdoms replace
   host APIs without semantic decomposition.
