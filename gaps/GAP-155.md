## Ruling

The file-scope tail is the program. No source `main` / `entry` wrapper.
Physical `_main` is linker ABI, not a source binding.

A module with a file-scope tail or statement sequence is the process. Helpers
in the same file are not promoted to the entry. A declared source `main` remains
deliberate and still wins.

Root applications have the module as caller. Unknown effect/authority/witness
stay unknown — not `world=""`.

## Remaining (not this gap)

1. Missing `os.args`/`os.env`/`os.cwd`/`path:read` is still a NULL hole
   (GAP-118: not a graph unknown; not `""`). Native no longer lowers
   `os.env(k)` — that call is refused; `os.env[k]` is the face. Corpus
   call spellings remain migratable debt.
2. Source `main: i64 = ()` teaching examples still in the corpus — migratable
   once this face is the default. Do not bulk-rewrite.
3. Effect/authority/witness on the root application remain unknown (lane 3).
4. A str *value* tail is discarded after production — it does not become an
   observed result (no silent stdout write). Observation is an admitted
   relation (`stdout:write`), not an invented egress.
5. **RESOLVED for MCP — native sentinel-free server on `idol run` (2026-08-13).**
   `tools/mcp/native.id` is a persistent JSON-RPC MCP server that runs on the
   direct native backend with **no `--backend=c`** and no Lua runtime. It serves
   `initialize`, `notifications/*` (ack), `tools/list`, `tools/call`, and `ping`;
   tool bodies (`status`, `head`, `orient`) run through `gatecap` + `jq -Rs .`.
   Verified end-to-end: ids `42/100/7/256` round-trip correctly, notifications
   ack, clean EOF exit 0.
   - **No sentinels (PREDICATE-ZERO).** Dispatch is entirely `line:has(needle)`
     presence facts consumed in refinement `if`; `find` results are used only as
     substring coordinates guarded by a `has` fact — never compared to a
     not-found sentinel. There is no `== 0` / `== ""` / `== nil` / `== true`.
   - **EOF is not a value.** `idol_io_read_line` (`src/idol_io_bootstrap.c`) ends
     the process on peer close, so the loop is `while true` with no empty-string
     EOF flag. stdout is line-buffered (`__attribute__((constructor))`) so each
     response reaches the peer before the next read.
   - New native line-read primitive wired through `native_ir.zig`, `main.zig`
     (symbol→bootstrap.c link), `dnir_lower.zig` (`lowerStdinLine`, `exprIsStr`
     for `stdin:line` and `gatecap`), `sema.zig`, `codegen.zig`, and
     `native_bootstrap.zig` (`stdin:line` method admission).
   - The native backend rejects nested method-calls-as-arguments and any block
     whose tail is a bare expression-statement when `allow_return=false`
     (`codegen.zig:4003` `block-tail-no-return`); the server therefore uses flat
     loop-body bindings and reads the next message as the loop-body tail
     statement.
   - Manifest: `tools/node/dev/mcp.manifest.json` now lists a `native`-backend
     `idol` server pointing at `tools/mcp/native.id`. The stale
     `bench.id` / `lsp.id` / `zls.id` (Lua-compat `std.*` / `then` / `end` / `~=` /
     `:push`) remain bootstrap-compatibility debt and are still gate-deferred.
   - `.cursor/mcp.json` is environment-protected (not writable from the harness);
     point it at `idol run tools/mcp/native.id` (no `--backend=c`) manually.
6. **Gate execution still native-blocked — advanced application frontier
   (2026-08-13).** `gate/idiom.id` compiles and passes `idol check`, but
   `idol run gate/idiom.id` exits 128 with its control self-tests failing
   (`subject(tail)`, `subject(has)`, `subject(read)`, `subject(eq)`) regardless
   of stdin. The primitives themselves are fine — string `==`, `:has` / `:find` /
   `:sub`, and early `return` from inside a `while` each execute correctly in
   isolation (probed). The gate fails because it uses **curried
   relation-projection application**: `subject(tail) = (code)` invoked as
   `subject(tail)("...")`, plus composed helper chains. The native subset does
   not yet execute that application shape, so the pre-commit hook stays
   `idol check` and no runtime sentinel/idiom conviction of the corpus is
   possible. Sentinel enforcement source is present and strengthened in
   `gate/idiom.id` (`== nil` / `!= nil` / `~= nil` / `= nil`,
   `== 0` / `!= 0` / `~= 0` / `== 1`, `== true` / `== false` / `~= true` /
   `~= false`, `== ""` / `~= ""` / `!= ""`), but only convicts on added diff
   lines once the gate can execute.
