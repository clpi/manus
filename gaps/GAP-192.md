# GAP-192 — dynamic programming and fixed-point synthesis via relation tabled memoization

**Status:** OPEN · **Filed:** !2026-08-18T16:40:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/recurrence.zig, src/demand.zig

Synthesize efficient dynamic programming algorithms automatically from declarative
recursive relations via tabled memoization and fixed-point closure. Tabled logic
programming (XSB) proves that memoizing subgoal answers converts exponential
depth-first recursion into polynomial fixed-point evaluation. In Idol, memoization
is a candidate physical realization of pure relation identity, not a user-level
decorator or cache.

## Current measured boundary

Recurrence recognition handles simple induction variables and affine loops in
`src/recurrence.zig`. General recursive subgoals without closed forms execute as
exponential call stacks.

**Crossed:**

- Recurrence closure and basis search implemented in `src/recurrence.zig`.
- Relation purity and identity tracking operational.

**Still missing:**

- Tabled relation realization candidate: subgoal identity -> memoized answer table.
- Automatic synthesis of bottom-up tabular DP from top-down recursive definitions.
- Automatic table dimension and bounding inference from argument domain facts.
- Fixed-point iteration over cyclic recursive dependencies (e.g. graph reachability,
  parsing, dataflow analysis).

## Required order

1. Formalize tabling and memoization as admissible realizations in C0.
2. Implement fixed-point detector for pure recursive relations.
3. Infer optimal table representations (flat array, hash, sparse, circular buffer).
4. Lower tabling candidates to direct array indexing when argument domains are bounded.
5. Prove complexity class reduction (e.g. $O(2^n) \to O(n)$ on Fibonacci / knapsack).

## Closure acceptance

Close when pure recursive definitions (dynamic programming, reachability, parsing)
automatically synthesize polynomial tabular realizations without manual caching code.
