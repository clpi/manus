# GAP-077 — `a, b = b, a` assigns left-to-right and silently corrupts data

**Status:** OPEN · **Filed:** 2026-08-08 · **Severity:** SILENT WRONG ANSWER

Multiple assignment is not simultaneous. The right-hand side is not evaluated
into temporaries before any target is written, so the canonical swap destroys
one of its own operands.

## Repro

```duo
main(): i64
    t = { 3, 7 }
    t[1], t[2] = t[2], t[1]
    print(t[1])
    print(t[2])
    return 0
end
```

```
prints   7 7        correct is 7 3
```

Verified under `--backend=c`. `t[1]` is written from `t[2]` first, and then
`t[2]` is written from the ALREADY-OVERWRITTEN `t[1]`.

## Why this one is nastier than most

`a, b = b, a` is the swap every programmer reaches for, in every language that
has multiple assignment, and it is correct in all of them — Lua included, which
matters because Duo is a Lua superset and this is the reflex a Lua reader brings.
The FAMILIARITY LAW (Pass 115) says every surface must explain itself through
reflexes the reader already has. This surface uses the reflex and then violates
it.

It also fails silently and plausibly: `{7,7}` looks like a swap that half
worked, not like a language defect, so the natural reaction is to doubt the
surrounding code.

Found during the Pass 119 semicolon migration, where one-line swaps
(`tmp = a[i]; a[i] = a[j]; a[j] = tmp`, 30 of them) were the largest population
of code semicolons. The obvious de-glued rewrite is `a[i], a[j] = a[j], a[i]` —
which would have introduced this corruption into thirty call sites. Every
migrated swap kept its temp instead.

## What the fix must preserve

Pass 100 B-9 and the pack machinery mean the right-hand side is already a pack
in the general case (`v, err = f(x)`). The rule is that **all right-hand values
are realized before any target is written** — which is what makes the failure
pack correct too, and is presumably why the pack case works while the
element-assignment case does not.

Check both when fixing:

```duo
t[1], t[2] = t[2], t[1]        -- must give 7 3
a, b       = b, a              -- plain locals, same requirement
v, err     = f(x)              -- must not regress
t[i], t[j] = t[j], t[i]        -- computed indices, both evaluated once
```

The last row matters: if the fix introduces temporaries, the INDEX expressions
must be evaluated once each, not twice, or a swap with side-effecting indices
changes meaning.

## Verify

Print the values; do not return them. Exit codes are 8-bit and a two-element
swap is easy to misread through a status.
