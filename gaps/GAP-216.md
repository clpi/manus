# GAP-216 — 128 declared answers have no live checker

**Status:** OPEN · **Filed:** !2026-08-22T05:30:00Z
**Priority:** P0 · **Kind:** evidence_gap
**Filed by:** claude-gap145
**Files:** scripts/boring_corpus.id,scripts/capability_table.id,scripts/native_differential.id

The example corpus declares its own expected answers. **Nothing reads them.**
Two independent breaks, either of which alone would be sufficient.

## Break 1 — the spelling moved and the checkers did not

```
files carrying `# expect:`    128
files carrying `-- expect:`     1
```

`scripts/boring_corpus.id` and `scripts/native_differential.id` both grep for
`-- expect:`:

```
sed -n 's/^-- expect: *//p' {path} | head -1
"  FAIL  {name}  carries no '-- expect:' line\n"
```

GAP-145's comment migration retired `--` in favour of `#`. The corpus moved;
the checkers did not. **128 declared answers were silently disconnected from
the only thing that compares them.**

## Break 2 — the checkers do not run at all

`scripts/boring_corpus.id`, `scripts/capability_table.id` and
`scripts/native_differential.id` all fail to compile at HEAD — `print-arg:any`,
`ret-type:any`. So even with the right spelling there is nothing to run.

## What it cost, measured

`examples/table/strnul.id` declares `# expect: 3`. It measures **1**. Its own
comment claims *"this row was red earlier in the epoch and is now green."*

That is the complete answer to *why nothing caught the NUL-truncation class*:
the answer was written down, the file says it is green, and no live instrument
has compared the two since the comment migration.

## The class

This is GAP-212 one level up. GAP-212 found 27 cited gates that never existed;
this is a checker that exists, is cited, and reads a spelling the corpus stopped
using. **A dead instrument and a mis-addressed one are indistinguishable from a
passing one** — both are silent.

## Acceptance

1. The checkers compile and run.
2. They read `# expect:`, and a file carrying `# expect:` that answers something
   else **fails**.
3. Positive control: `examples/table/strnul.id` must be **red** on the first
   run, because it declares 3 and measures 1. A checker that reports the corpus
   green on day one has not been connected — that is exactly the state being
   filed.
