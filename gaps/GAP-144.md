## Semantic and correctness defects

| # | directive |
|---|---|
| 1 | The branch also introduces or relies on these invalid boundaries: |

1. An unwritten or out-of-range element is represented as integer zero. Absent,
   present zero, and invalid index are therefore not recoverable semantic cases.
2. `len` is the highest positive index written, not a proved table length law.
   Indices below one are silently ignored while fixed tables use a different
   behavior.
3. Growth emits `BinOpTag`, `br_if_not`, `store_local`, `load_index`,
   `store_index`, `mov_arg`, and `call_extern`. Current `main` has already
   removed the split conditional branch vocabulary, and the remaining names are
   migration storage or realization facts, not semantic relations.
4. `calloc`, `realloc`, and `memset` are selected by callee text. Allocation
   failure, size overflow, ownership, lifetime, and effect/world facts are not
   carried. A failed `realloc` overwrites the only base value before any failure
   handling, losing the old allocation.
5. Five function-wide scratch places are introduced to avoid a known broken
   register-spill path. This canonizes a backend defect as lowering architecture
   and does not preserve the maximum lawful realization set.
6. The representation only stores `i64`, so it is neither the general Idol
   table law nor a witnessed Lua-table realization.

| # | directive |
|---|---|
| 1 | The branch merges textually with current `main`, but textual mergeability is not semantic compatibility. |
| 2 | It predates the checked application-lineage and branch factoring work and contains no differential, allocation, latency, C-floor, or Wasm evidence. |

## Required reimplementation boundary

| # | directive |
|---|---|
| 1 | A current-main replacement is admissible only when all of these are true: |

1. The graph supplies exact table value identity, descriptor/shape, element
   cases, demand, alias/lifetime, effects/worlds, and legal representation
   candidates. No source-name map or future-syntax scan selects realization.
2. Absent, present zero, invalid index, empty, and length are distinct according
   to the admitted table law. Physical niches may be used only while those cases
   remain recoverable.
3. Materialization and growth occur only when observation demands addressable
   storage. An SSA/table value does not become a place because the host used a
   binding or subscript node.
4. DNIR consumes canonical semantic relation and value identities. Allocation,
   linkage, ABI, branch sense, place kind, and register placement remain facts or
   realization obligations rather than new semantic operations.
5. Allocation failure, multiplication overflow, ownership transfer, lifetime,
   and reclamation are explicit and tested.
6. The implementation is Idol-owned, or any remaining foreign bridge is the
   smallest local projection with an exact deletion gate into the Idol owner.
7. Canonical fixtures cover empty access, present zero versus absent, growth,
   aliases, rebinding, nested use, call boundaries, negative/zero indices,
   length, allocation failure, and overflow.
8. Direct-native and C differentials agree, zero silent fallback is proven, and
   allocation/copy counts plus latency establish at least the C floor on a
   transferable runtime-sized workload. Ward/Wasm claims require their own
   measured runtime path.

## Negative controls

| # | directive |
|---|---|
| 1 | Four of the six are PINNED by `gate/gap-144-table-identity.sh` on the generated-C path; two are pinned by nothing. |
| 2 | Which is which is part of the control, so it is recorded here and not left to be rediscovered. |

- PINNED — Renaming a source binding while preserving its semantic value
  identity cannot change table representation or behavior. Asserted in the
  graph export, the emitted C and the observed values, over two pairs: an
  empty table grown through a length read, and a table crossing a call
  boundary and rebound inside the callee.
- PINNED — Aliasing the same table cannot mint another table identity or lose
  mutation. A write through the second name is read back through the first,
  and the first name's earlier write is read back through the second.
- PINNED — Present integer zero must remain distinguishable from absence, with
  the rest of required-boundary item 2's case set: absent, present zero,
  invalid index, empty and length are asserted as five distinct observations.
- NOT PINNED — Removing authoritative table demand or identity must fail closed
  rather than falling back to an AST/name census.
- PINNED — Changing ABI, allocator, or target cannot change the canonical
  table relation identities. The graph publishes the relation identities and
  the realizations are measured against it, over three knobs — target, link
  ABI, and allocator — each of which must be proved to have reached something
  before its invariance counts.
- NOT PINNED — A folded or specialized access retains the original table value,
  relation, application, and source provenance through machine byte ranges.
