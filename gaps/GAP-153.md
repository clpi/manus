## Ruling

Canonical **import is deleted**. Do not add or restore `import`, `module`,
`package`, `namespace`, `include`, `require`, `req`, `use`, `using`, `inject`,
`admit`, `open`, `bring`, `provide`, `register`, `install`, `mount`, or
`expose` as semantic permission, visibility admission, or loader mechanisms.
Bootstrap `req("std.*")` and historical corpus uses are migration debt only.

Native reachability is **projection** over ordinary values, tables/homes,
bindings, scope facts, and anchored roots — not admission syntax in source.
There is no operation meaning “make this already-known thing visible here.”
Change scope facts at the owner boundary instead.

Do not create privileged module edges: `filebind`, `modulebind`, `packagebind`,
or `sourcebind`.

A file is not a module construct. A file contributes an ordinary table into an
ordinary lexical/table graph. The filesystem is provenance and discovery; it
must not manufacture a second semantic abstraction.

See `docs/spec/source.md` for the full projection / scope / package / capability
closure.

## Three orthogonal facts

| fact | answers |
|---|---|
| home | where does this meaning live? |
| reach | can this scope resolve this meaning? |
| world | what authority can this application exercise? |

**Package/table ≠ world.** A directory is an anchored home, not an authority
world. Possession of a table never implies possession of a world.

## Source layout → table topology

Given:

```text
compiler/
    lexer.id
    parser.id
    graph.id
```

the compiler derives (nobody writes the wrapper):

```text
compiler.lexer
compiler.parser
compiler.graph
```

Inside `compiler/parser.id`, sibling resolution is direct:

```id
tokens = lexer:scan(source)
g = graph:new()
```

No dependency syntax. The **reference is the dependency fact**.

Same-directory references require nothing: if `a.id` and `b.id` share a home,
`b:foo()` resolves as a sibling binding — statically, graph-native, with
incremental invalidation from actual semantic references.

Cross-directory visibility uses **anchored root tables** provided by build/project
configuration (an ordinary binding such as `codec`), not per-file import
declarations. Unused dependency elimination follows from the reference graph.

## Resolution ladder (shape)

```text
local bindings
→ enclosing table/home
→ enclosing home ancestors
→ explicitly projected bindings
→ provided root anchors
→ canonical vocabulary
→ failure (ambiguity diagnosed, not order-selected)
```

Exact canonical order is implementation work; architecture is fixed.

## Implementation invariant for agents

**Never load a file. Resolve a table.**

Files and directories are source provenance for ordinary semantic tables. A
reference to a sibling or anchored table is the dependency edge. No req,
require, import, module registry, runtime namespace table, package loader, or
admission syntax participates in native semantics. Worlds remain authority values
resolved by existing world law, but possession of a table never implies
possession of a world.

Agents must not introduce host-shaped concepts (`Module`, `PackageLoader`,
`StdTable`, `WorldRegistry`, …) when graph facts suffice.

## Acceptance

1. Constitution, `docs/spec/source.md`, and operative projections state the
   model above without reintroducing import-as-permission or admission-as-visibility
   (aligns with `law.authority.grant`, `law.distribution`, `law.layout`,
   `law.projection`).
2. New canonical `.id` adds no `req` / `require` / `import` / `using` / `use(` /
   `inject` / `admit` / `module` / `namespace` / `include` / privileged `*bind`
   loader or admission surface (`idiomgate` and `gates/path` remain blocking).
3. Compiler resolution path derives home topology from source layout and records
   reference-induced dependency edges without a separate import graph.
4. Bootstrap `req("std.*")` count ratchets down as prelude graph facts replace
   loader calls.

## Disjoint debt

Embedded @c governance uses separate single-word gate roles — **floor**
(unclassified foreign files in `foreign_census`), **advertise** (aggregate @c
count), **audit** (per-file sites in `embedledger`), **enforce** (zero-site
gate) — not compound labels like `embedfloor` or `edge audit`.
