# GAP-178 — persistent equivalence saturation as a graph fact

**Status:** OPEN · **Filed:** !2026-08-18T15:00:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/semantic_graph.zig, src/obseq.zig

Generalize the local `obseq` e-graph experiment into one persistent graph-wide
equivalence structure. Equivalence becomes a durable graph relation over
semantic identities, surviving transformations and allowing independent
producers to publish equivalent realizations. It supports both optimization and
translation validation.

## Current measured boundary

`obseq` implements a specialized quotient-aware e-graph and has produced real
loop-elimination results. It is not yet a generalized persistent substrate that
outlives a single optimizer pass.

**Crossed:**

- Local e-graph / congruence closure exists and works for narrow recurrence
  structures.
- Equivalence is recognized as distinct from the semantic graph.

**Still missing:**

- `id A ≡ id B under O, W, F` as a first-class graph relation.
- Equivalence witnesses that survive across compiler stages.
- Independent producers publishing realizations to the same equivalence
  structure.
- Proof-carrying extraction: each equivalent carries its observation set,
  world, and provenance.
- Translation validation: original and selected output remain represented in
  the same equivalence structure.
- `obseq` as one client of the substrate, not the only implementation.

## Required order

1. Define `equivalence` as a graph fact over semantic ids under an observation
   set, world, and fact set.
2. Separate the semantic graph from the equivalence structure.
3. Add equivalence witnesses and proof-carrying extraction.
4. Make the local `obseq` e-graph a client of the substrate.
5. Use the persistent equivalence structure for translation validation and
   agent-proposed optimizations.

## Closure acceptance

Close when equivalence is a durable graph fact, when multiple realization
producers can publish to one structure, and when the original and selected
output of a transformation remain representable for translation validation.

## C0 alignment

Instance of the schema in `gaps/RESEARCH-SPINE.md`; `tools/node/dev/gapc0` fails
closed without it.

- **constitutional owners:** relation (`A ≡ B` is a witnessed relation over ids) · witness · trust · provenance
- **kind delta:** 0
- **registry delta:** 0
- **source syntax delta:** 0
- **semantic invariant:** equivalence is `A ≡ B under observation O, world W, assumptions F, witness P` — a fact qualifying existing ids, never a graph rewrite and never a second semantic graph.
- **physical mechanism:** an equivalence index/cache (permitted physical roles); proof-carrying extraction; translation validation.
- **prerequisites:** GAP-177.
- **foreign implication:** cross-origin equivalence uses the same witnessed relation (feeds GAP-183).
- **world implication:** equivalence is world-qualified.
- **projection implication:** none — no new faces.
- **demand implication:** equivalence holds under the demanded quotient only.
- **realization implication:** a transformation ADDS `A ≡ B under C` instead of deleting `A` — original and selected realizations survive for re-extraction and translation validation; `obseq` becomes one client.
- **evidence:** one transformation whose original and selected realization both survive for translation validation; multiple producers publishing to one structure.
- **deletion witness:** per-pass e-graph instances and destructive rewrites.
