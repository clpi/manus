# GAP-032 — a receiver face on an `any` receiver silently returns nil

**Status:** open · **Filed:** 2026-08-07 · **Frequency:** 1
**Cited at:** `lib/std/json.duo` · **Blast radius: 93 sites in lib/std**

## Repro

```duo
cur = { s = "hello", i = 2 }

string.byte(cur.s, cur.i)   -- 101   correct
cur.s:byte(cur.i)           -- nil   WRONG, no diagnostic

string.sub(cur.s, 2, 3)     -- "el"  correct
cur.s:sub(2, 3)             -- nil   WRONG, no diagnostic

#cur.s                      -- 5     the len face is FINE
```

The receiver must be a statically-known `str`. A table field is `any`, so the
method face does not resolve and yields nil instead of diagnosing. `#` is
unaffected, which is why the `string.len` -> `#` sweep was safe and the other
two were not.

A bare local does not help (`a = cur.s; a:byte(i)` -> nil). A **typed** local
does (`b: str = cur.s; b:byte(i)` -> 101), but adding the annotation can break
other uses of the same binding: doing it in json.duo produced 10 C errors,
`invalid operands to binary expression ('lua_Value' and 'int')`.

## What it broke

`std.json.decode` returned the number **0** instead of a table, so every field
access on a decoded value null-dereferenced:

    lua_table_get_raw_str_lit -> KERN_INVALID_ADDRESS at 0x68

`examples/nested_std_req_smoke.duo` died at exit 128 and took `agent-smoke`
with it. Bisected against the three corpus sweeps:

    string.len  -> #        d.ok = true, d.n = 7    fine
    string.byte -> :byte    empty table             BROKEN
    string.sub  -> :sub     empty table             BROKEN

**A shallow assertion hides this.** Checking `tostring(d)` alone reported
`d=table` for the `:sub` variant and the bisect looked clean; only asserting
the CONTENTS (`d.ok`, `d.n`) exposed it. Any audit of the remaining sites has
to read values, not shapes.

## Interim

`string.byte(x.y, i)` / `string.sub(x.y, i, j)` where the receiver is a table
field, cited `-- gap[032]`. Reverted in `lib/std/json.duo` on those grounds:
a denied spelling that works beats a canonical one that silently returns nil.

## The corpus debt

93 sites in lib/std match `\b[a-z]+\.[a-z]+:(sub|byte)\(` — a field receiver
carrying a face. They were converted mechanically by the `string.byte` (299
sites) and `string.sub` (369 sites) sweeps and are all suspect. They need
auditing by VALUE, not by compile success: every one of them compiles.
