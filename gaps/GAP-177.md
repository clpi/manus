## Current measured boundary

| # | directive |
|---|---|
| 1 | **Crossed:** |

- `law.change.delta` is documented in C0.
- Self-adjusting computation and incremental algorithms are cited as prior art.

| # | directive |
|---|---|
| 1 | **Still missing:** |

- `Δf(x, Δx) = Δy` for every relation `f`.
- Dependency delta, demand derivative, and minimum affected application
  frontier as graph facts.
- Integration with incremental compilation, build systems, reactive systems,
  streaming, database views, and agents.
- Automatic differentiation as a special case: `∂output/∂input` is a change
  quotient.
- Bidirectional projection (lenses/incremental relational lenses) so that
  `view = project(source)` and `Δview` can be propagated back to `Δsource`.

## Required order

1. Define `change` as a semantic relation: `f(x) = y` implies `Δf(x, Δx) = Δy`.
2. Add graph facts for dependency, demand derivative, and affected frontier.
3. Implement delta propagation through the same graph engine that evaluates
   forward semantics.
4. Show that incremental compilation and AD are realizations of the same
   change relation with different observers.
5. Generalize to bidirectional projections: `source → view` and `Δview → Δsource`.

- **constitutional owners:** relation (`Δf` is a relation) · place (a semantic locus where a lawful delta applies, not a physical address) · demand · provenance
- **kind delta:** 0
- **registry delta:** 0
- **source syntax delta:** 0
- **semantic invariant:** `f(x) = y` carries `Δf(x, Δx) = Δy` as a relation fact; places generalize to every locus admitting a lawful delta.
- **physical mechanism:** delta propagation through the same graph engine that evaluates forward semantics; affected-frontier computation.
- **prerequisites:** GAP-175, GAP-176.
- **foreign implication:** hot reload and foreign artifact updates are deltas over the same relations.
- **world implication:** world fact changes are deltas; incremental compilation is a graph delta, not compiler state.
- **projection implication:** `source → view` gains its lawful inverse `Δview → Δsource` where witnessed (with GAP-186).
- **demand implication:** the demand derivative — which consumers of `y` need which part of `Δy`.
- **realization implication:** recompute only the minimum affected application frontier; AD is a change-quotient specialization of one mechanism.
- **evidence:** one incremental workload recomputing only the affected frontier, measured against full recompute.
- **deletion witness:** incremental-compiler state machinery, reactive/diff subsystems, AD as a separate mechanism.
