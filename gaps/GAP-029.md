# GAP-029 — no legal spelling for a string built from a call result

**Status:** open · **Filed:** 2026-08-07 · **Frequency:** 7 sites in this diff alone
**Blocks:** Pass 83 §1 deny list vs STR-1 expression holes — the two are jointly unsatisfiable
**Sites:** `scripts/census/family.duo` (3), `scripts/census/modes.duo` (4), each cited `-- GAP-029`

## The defect

Two canon rules are individually reasonable and jointly impossible to satisfy.

- Pass 83 §1 denies `" .." / ".. " beside string literals`. Interpolation is the
  canonical spelling; `..` "only joins existing string bindings".
- Pass 83 §1 also denies `single-use next-line temporaries` (TMP-1) — "that's an
  unwritten chain".
- **STR-1 expression holes do not interpolate.** `"{bin()}"` emits the brace text
  literally, with no diagnostic. Only names and dotted fields resolve.

So for a string built from a **call result** there are exactly three spellings
and canon denies all three:

```duo
-- 1. concat beside a literal          → denied by §1
std.script.capture(bin() .. " run " .. path)

-- 2. expression hole                  → SILENTLY WRONG (emits the brace text)
std.script.capture("{bin()} run {path}")

-- 3. single-use temporary             → denied by §1 TMP-1
b = bin()
std.script.capture("{b} run {path}")
```

Spelling 2 is the one canon actually endorses, and it is the only one of the
three that produces a wrong program with no diagnostic.

## Minimal repro

```duo
f(): str
    "world"
end
main(): void
    print("hello {f()}")
end
```

```
hello {f()}
```

No error, no warning. Compare the name hole, which works:

```duo
main(): void
    w = "world"
    print("hello {w}")      -- hello world
end
```

## Resolution taken in this diff, and why

Spelling 3 — the single-use temporary — with `-- GAP-029` cited at each of the
seven sites. It is the lesser violation because it is **correct**: TMP-1 is a
style rule about unwritten chains, while spelling 1 is denied outright and
spelling 2 ships a wrong string. A style violation that runs beats a canonical
form that does not.

This should not be read as a request to relax TMP-1. TMP-1 is right about what
it describes — the temporary here is not an unwritten chain, it is an
**unwritable** one, and it disappears the moment expression holes land.

## The fix

Expression holes (STR-1). Once `"{bin()} run {path}"` evaluates, all seven sites
collapse to one line each and the temporaries go away with no other change. Until
then, a third rule is needed to break the tie — either TMP-1 exempts a temporary
whose only purpose is an interpolation hole, or the deny list exempts `..` where
an operand is a call.

Note the escape hatch is separately missing (GAP-16): there is no way to spell a
literal `{name}`, so a program whose data contains holes cannot opt out either.
The two together mean interpolation is currently mandatory, incomplete, and
inescapable.
