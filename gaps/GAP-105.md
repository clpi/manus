# GAP-105 — SHC is executed authority, not proof

**Status:** OPEN — the generated lexer route executes; canonical lexical and
grammar authority remain incomplete · **Filed:** 2026-08-09 · **Re-measured:**
2026-08-17

## Current boundary

`src/lexer_dispatch.zig` `route()` invokes Idol `tokenize()`. The
constant-valued `TokenizeAuthority` registry and its inactive host branch are
gone. The host scanner algorithm remains only as a field-for-field differential
oracle (`tokenizeHost` → `next_tok`).

That does not close SHC. Production still rebuilds host `lexer.Token` records
from producer records; `TokenKind` remains a parallel enum bound once by
`bindKindSchema`. GAP-145 identities (text/bytes/compat/long, comment,
shebang, dash comments, reserved backtick) now cross `tokenize()`. Remaining
GAP-145 debt is remaining semantic quote/source-law consumers and the
Tree-sitter lexical projection. Producer, host-token, and AST `string_lit`
identities are deleted; source-form/corpus admission now executes through
`sourceform*`, `sourceentry*`, and `sourcefact*`. Parser long-bracket source
reconstruction is deleted (level in `int_val`). Grammar roles remain
`GAP-134`. The tracked historical lexer path and generated-C bridge remain S0
migration debt. No compiler B.

SHC is measured by semantic decisions on the executed production path. Source
quantity, proof modules, generated artifacts, and constant authority switches
do not count.

## Remaining producer obligations

1. `GAP-145` must publish law-bearing lexical identities, source law,
   provenance, and exact spans at recognition. Downstream token text may not be
   searched to reconstruct them.
2. `GAP-134` must derive grammar roles and an immutable token view from the
   canonical grammar owner.
3. The temporary host enum/name ABI must disappear when compiler B consumes
   the same executed source-law contract directly.
4. The first parser recognition must consume those identities and roles. Do
   not port the historical parser module or add another generated-C semantic
   stage.

## Admission and closure

- Removing or corrupting a required lexical fact fails before parser meaning is
  accepted.
- Storage and transport failures do not resume the host scanner.
- The host scanner remains an oracle only while the complete generated-fact
  differential is demanded.
- Compiler B evidence must observe the canonical Idol source, graph facts,
  backend, world, provenance, diagnostics, and artifact. A proof file or a
  generated artifact is not compiler B.

This gap closes when the bootstrap ledger can derive the lexical and grammar
rows from executed canonical facts without an authority registry or host token
vocabulary. The 2026-08-09 module and line-count snapshot is historical; Git
history, not this live obligation, retains it.
