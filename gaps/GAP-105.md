## Remaining producer obligations

1. `GAP-145` must publish law-bearing lexical identities, source law,
   provenance, and exact spans at recognition. Downstream token text may not be
   searched to reconstruct them.
2. `GAP-134` must derive grammar roles and an immutable token view from the
   canonical grammar owner.
3. The temporary host enum/name ABI must disappear when compiler B consumes
   the same executed source-law contract directly.
4. The first parser recognition must consume those identities and roles. Do
   not port the historical parser module or add another generated-C semantic
   stage.

## Admission and closure

- Removing or corrupting a required lexical fact fails before parser meaning is
  accepted.
- Storage and transport failures do not resume the host scanner.
- The host scanner remains an oracle only while the complete generated-fact
  differential is demanded.
- Compiler B evidence must observe the canonical Idol source, graph facts,
  backend, world, provenance, diagnostics, and artifact. A proof file or a
  generated artifact is not compiler B.
