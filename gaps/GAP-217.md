## Deletion witness
- Semantic entity? No. A call-site shape fingerprint is a physical index.
- Already in the graph? The application, its operands and its result have
  semantic identities. This hash is a fourth, weaker name for the same site.
- Survives renames / AST movement? No — `callee_name` is hashed, so a rename
  changes the "provenance" of an unchanged transform. Measured above.
- Deletion condition: stated in-tree. Delete with the `identityHash` call
  sites once provenance carries semantic value ids.
- Could two stores disagree? Yes, and they already do: this hash disagrees
  with semantic identity under rename in one direction and under total body
  replacement in the other.
