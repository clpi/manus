| # | directive |

| 1 | Zig does not require a companion `*Kind` enum. §0.3's canonical form — `kind: { name, number, eof }` inline at the field — has a direct Zig spelling (an anonymous enum field, or a tagged union whose tag is the node itself). |

| The repair, in order |

| # | directive |
|---|---|
| 1 | **A ratcheting scan over `src/*.zig`** for the rows the deny table already defines — `upper`, `companion`, and the ARCH-RELATION shapes (`addNode`, `addEdge`, `addChild`, `register*`, `emit*`). Ratchet DOWN. This is the item that makes the rest real; without it every repair is voluntary. |
| 2 | **Every host API names the relation it projects** (`law.host.projection`), carrying `authority = false`, its semantic owner, and its deletion gate. An API that cannot name its relation is the finding. |
| 3 | **`NodeKind`/`EdgeKind` demote to indexes**, not ontology — already ruled in C0 (`kinds.role = .index`, `kinds.authority = false`). Delete `directive`, `concept` and `pipeline` when the demotion lands; they name nothing. |
| 4 | `addChild` has no semantic existence (`law.fact.one`); `parent contains child` is the fact. |
