# GAP-084 — the noun census: 293 mechanisms where the constitution names 6

**Status:** OPEN · **Filed:** 2026-08-08
**Law:** `law.fact.primitive` (the irreducible primitives are value, relation,
fact, world, demand, witness) · `law.arch.relation` · `law.add.open` ·
A2 NNS · A3 ONE EDGE
**Metric:** MCR — Mechanism Compression Ratio, *independent mechanisms a
conventional architecture needs / irreducible duon mechanisms*

## The question this answers

> *"What remaining thing in duon still has a NOUN because we haven't yet
> discovered that it is merely a relation, fact, demand, world, witness, or
> realization?"*

Measured over tracked `src/*.zig`, 2026-08-08. This is the list.

| mechanism-bearing form | count |
|---|---:|
| enums | **229** |
| `*Registry` / `*Manager` / `*System` / `*Table` / `*Catalog` | **64** |
| `add*` / `register*` / `emit*` functions | 45 |
| `resolve*` / `find*` / `lookup*` / `get*` functions | 66 |
| **irreducible primitives named in `constitution.duo`** | **6** |

Some of the 64, verbatim, because the names make the case better than the count:

```
AliasRegistry           DeriveRegistry          ProtocolRegistry
NativeDeriveRegistry    MissingTransformRegistry UserBundleRegistry
proveDecisionRegistry   proveKeywordRegistry    proveProtocolRegistry
proveDescriptorInternRegistry   proveIrLayerRegistry
proveSemanticOperationRegistry  proveRejectedSyntaxRegistry
proveGuidingRulesRegistry       proveDeferredAccumulatorRegistry
```

`ProtocolRegistry` is a noun for something §8 already calls a **relation**.
`DeriveRegistry` is a noun for `derive`, which the constitution lists as an
ordinary relation. `proveSemanticOperationRegistry` is a noun for a *set of
facts about semantic operations* — three concepts the primitives already carry,
compounded into one host object.

## The reading

The constitution says six primitives suffice and everything else is a *family of
facts*. The bootstrap carries **293 mechanism-bearing nouns** against those six.

That ratio is not itself the finding — a bootstrap in a host language will
always have more nouns than the law it implements. The finding is **which**
nouns, and that they are not host necessities:

- `ProtocolRegistry` is not required by Zig. Zig requires a map; the *protocol
  registry* concept is a design choice on top of one.
- `DeriveRegistry` names a relation the constitution already names.
- The `prove*Registry` family — nine of them — are catalogs of facts, which is
  the definition of the `fact` primitive.

`law.host.projection` grants un-duon-like structure ONLY where the host requires
it. A `std.AutoHashMap` is required. A noun that duplicates a constitutional
primitive is not.

## Why this is the highest-leverage remaining measurement

MCR multiplies where the others add. SER (gap[082]) and RSR (gap[084a], below)
each measure ONE dimension's leverage. MCR measures whether the *dimensions
themselves* stop multiplying — and the constitution's claim is that they do,
because relations compose where subsystems do not.

Each of these 64 nouns is a candidate for the challenge in
`law.arch.relation`: **is this distinction recoverable from operands, levels,
homes, lawsets or context?** If yes, the noun is bootstrap debt with a deletion
gate. If no, it is a genuine mechanism and the constitution's list of six is
incomplete — **which would be a finding about the constitution**, and worth more
than the repair.

## Companion measurement — RSR is 1

*Realized Specialization Ratio: distinct optimized machine realizations per
authored semantic body.* The design target is combinatorial — one kernel
yielding thousands of realizations across descriptor × ISA × layout × ownership.

Measured: an untyped `twice = (x) x + x` called at both `i64` and `f64` emits
**zero specialized definitions** — it goes boxed, one dynamic path. A typed body
emits exactly one.

**RSR = 1.** One authored body, one realization. Together with **SER = 1**
(gap[082]), both metrics that "prove duon is actually delivering" currently
read 1, and both are honest baselines rather than failures — nothing has claimed
otherwise, and now nothing can.

## Fix, in order

1. **Classify all 64 nouns** — `index` / `cache` / `projection` / `bootstrap`
   per `law.host.projection`, or **semantic-open violation**. Unclassified is a
   finding. `zig build bootstrap-scan` already ratchets the 45 `add*` and the
   companion enums; extend it with a `noun` row.
2. **The `prove*Registry` family first** — nine nouns for one concept (a catalog
   of facts) is the clearest collapse available and touches no lowering.
3. **`ProtocolRegistry` and `DeriveRegistry`** name relations the constitution
   already names. They are the two that make the argument.
4. **Publish MCR with its denominator**, exactly as SER needs its N: "293
   mechanisms against 6 primitives" is a measurement; "49× compression" without
   the noun list is marketing.
