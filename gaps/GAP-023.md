# GAP-023 — two lexer proofs regress when the compiler lexes itself with Duo

**Status:** open · **Filed:** 2026-08-07 · **Frequency:** 1
**Blocks:** SH-03 `tokenizeAuthority() == .duo_native` (the last step)

## The observation

With the flag on, everything structural passes — the compile-fail suite is
byte-identical to the host baseline, parser coverage is 256/256, selfhost proofs
are 12/12, repo-hygiene passes, and the file that previously panicked
(GAP-022) checks clean. Four things regress:

    examples/pass16_lexer_fingerprint_differential.duo   exit 3
    examples/pass16_lexer_text_differential.duo          exit 3
    c_sim_import.test: point.h -> SIM entities
    native_barrier_checks.test: pass12_m1 branch_chain body passes no_boxing

Exit 3 is each proof's own assertion code, so they COMPILE and then disagree.

## The hypothesis — explicitly not a diagnosis

Both proofs carry **lexer corpus data as string literals**. They are therefore
the programs most sensitive to how the compiler lexes string literals, which is
precisely what changes when the compiler lexes itself with the Duo lexer.

This has the same shape as a failure already recorded in this repo: a blanket
`~=` pass once rewrote a lexer's own corpus data, and `scripts/spec_conformance.duo`
had its test PROGRAM interpolated as if it were the harness's own source
(GAP-016). Data that is itself source is the recurring trap here.

It is a strong hypothesis and nothing more. It has NOT been isolated, and the
two unit-test failures are unexplained by it.

## Where to start

1. Diff the two proofs' token streams under both authorities — the
   `differential()` in `src/duo_lexer_dispatch.zig` already does this for
   arbitrary source and currently passes on all 8 of its cases, so feed it the
   proof files themselves. If it stays green on them, the divergence is NOT in
   tokenization and the hypothesis above is wrong.
2. `c_sim_import` and `native_barrier_checks` touch neither strings nor the
   lexer obviously; they may share a cause with the proofs or be separate.

## Established

The seam beneath the flag is complete and proven: artifact linked into the
production binary, dispatch verified LIVE (corrupting the Duo stream by one
token makes the compiler fail to parse), token streams equal field for field,
rejections instead of aborts (GAP-017), source-slice text (GAP-022). The
remaining work is this divergence, not the plumbing.
