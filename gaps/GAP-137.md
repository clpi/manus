# GAP-137 — SHC-01 DNIR application identity remains optional and fail-open

**Status:** OPEN · **Filed:** !2026-08-10T01:08:39Z
**Priority:** P0 · **Kind:** backend
**Filed by:** codex-root
**Files:** src/sema.zig,src/semantic_graph.zig,src/dnir_lower.zig,src/native_backend.zig

The current bootstrap bridge adds optional relation, application, and result
hashes to DNIR for a subset of checked subject calls. It does not close SHC-01.
The relation is not the selected callable identity, ordinary and uncovered calls
can still lower without it, callee text continues to select the implementation,
and public object emission carries no queryable machine lineage. Call labels,
operand descriptors, constants, world, return-pack shape, witness, provenance,
and meaning/content/incarnation identity are also absent. Repair must begin with
the Duon-owned application facts, then carry the same selected identity through
a fail-closed lowering and public machine projection without a name/op
translation table.

## 2026-08-10 rejected prototype

A nine-path Zig prototype added 739 lines and removed 195 while projecting a
checked application through Sema, the semantic graph, DNIR, regions, and ARM64
byte ranges. Two independent reviews rejected it before commit. The prototype:

- used a store-local relation family rather than the selected callable identity;
- made the DNIR application reference optional and allowed production fallback;
- lost labels, operand descriptors, constants, world, and return-pack shape;
- continued to select calls, transforms, and machine branches by callee text;
- discarded lineage at the public object boundary; and
- added host semantic machinery without a Duon owner or deletion trigger.

A real current-source unit run remained at the known baseline, 1165 of 1168,
but that is only regression evidence and does not establish the semantic
contract. The prototype was rolled back. This gap remains open. The next slice
must establish the Duon-owned application/fact representation first, then add
only the smallest fail-closed, deletable Zig projection needed to carry the
same identity through realization.
