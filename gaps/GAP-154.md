## Acceptance

1. `docs/spec/host.md` and operative projections state host closure without
   reintroducing host namespace authority.
2. Agent routers require `docs/spec/host.md` before transport, args, environment,
   process, or shell work.
3. `./tools/node/dev/hostcensus` reports classified host-pattern counts; new
   native host-pattern debt on added canonical lines is zero.
4. MCP, the durable sibling LSP, gates, and build tools classify retained host calls as
   FOREIGN/BOOTSTRAP/MIGRATION with deletion gates.

## Negative controls

- Environment observation without compatible world: fails.
- Structured command without process world: fails.
- Unknown bare command in ordinary home: unresolved — not silent exec.
- Same source under shell home: structured command — not `popen` string.
