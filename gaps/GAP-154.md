## Ruling

Idol source sees semantic values — not host operating system APIs.

Host spellings (`os.args`, `os.getenv`, `popen`, `io.popen`, `os.execute`,
stdin-only architecture, `--backend=c` as semantic switch, runtime `std`/`core`
namespaces) are foreign ingress/egress or bootstrap debt until decomposed into:

```text
root/home projected values (args, environment, input, output, error, cwd)
worlds (fs, net, process, …)
structured command + process world for execution
endpoint polymorphism by embedding
shell home + command projection for bare external commands
```

Do not rename host APIs without semantic decomposition.

Do not add host API calls, host-shaped wrappers, or spelling-detector authority
until production semantic enforcement exists for the affected boundary.

## Acceptance

1. `docs/spec/host.md`, constitution, `docs/spec/source.md`, and operative
   projections state the closure without reintroducing host namespace authority.
2. Agent routers (`AGENTS.md`, `CLAUDE.md`, `.agents/*`, `.cursor/rules/*`,
   `.pi/skills/idol-dev`) require `docs/spec/host.md` in session read order.
3. `./tools/node/dev/hostcensus` reports classified host-pattern counts; existing
   violations ratchet down; new native host-pattern debt on added canonical
   lines is zero (`scripts/idiomgate.id` temporary firewall).
4. MCP/LSP/gates/build tools classify retained host calls as
   FOREIGN/BOOTSTRAP/MIGRATION with deletion gates — no unclassified hits in
   agent-facing surfaces.
5. Minimal canonical teaching examples exist for args/environment/endpoints/
   command/process world / ordinary home vs shell home (or recorded as blocked
   on vocabulary).

## Negative controls

- Root without `args` value: argument access fails.
- Environment observation without compatible world: fails.
- Structured command without process world: fails.
- Unknown bare command in ordinary home: unresolved — not silent exec.
- Same source under shell home with command projection: resolves to structured
  command — not `popen` string.
- Removing runtime std/core/prelude table: canonical vocabulary still resolves.

## Disjoint debt

Production semantic gates for host/process/environment remain blocked on graph
authority (`GAP-124`, binding/scope frontier). Lexical firewalls are migration
pressure only until then.
