## Ruling

Idol source sees semantic values — not host operating system APIs.

Host spellings (`os.args`, `os.getenv`, `popen`, `io.popen`, `os.execute`,
stdin-only architecture, `--backend=c` as semantic switch, runtime `std`/`core`
namespaces) are foreign ingress/egress or bootstrap debt until decomposed into
worlds, structured command, and endpoint projection. `docs/spec/host.md` owns
this boundary. Shell is an execution home, not a second host API.

Do not rename host APIs without semantic decomposition.

## Acceptance

1. `docs/spec/host.md` and operative projections state host closure without
   reintroducing host namespace authority.
2. Agent routers require `docs/spec/host.md` before transport, args, environment,
   process, or shell work.
3. `./tools/node/dev/hostcensus` reports classified host-pattern counts; new
   native host-pattern debt on added canonical lines is zero.
4. MCP/LSP/gates/build tools classify retained host calls as
   FOREIGN/BOOTSTRAP/MIGRATION with deletion gates.

## Negative controls

- Environment observation without compatible world: fails.
- Structured command without process world: fails.
- Unknown bare command in ordinary home: unresolved — not silent exec.
- Same source under shell home: structured command — not `popen` string.

## Disjoint debt

Production semantic gates for host/process remain blocked on graph authority
(`GAP-124`). Lexical firewalls are migration pressure only until then.
Root execution (file-scope tail as the process) is GAP-155, not this gap.
