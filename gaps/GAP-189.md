# GAP-189 — recovery / continuation algebra

**Status:** OPEN · **Filed:** !2026-08-18T16:20:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/continuation.id, src/condition.id

Effects are not only "what occurred." A condition is a semantic fact, and the
admissible recovery continuations are themselves semantic capabilities. This
unifies return, exception, yield, async, generator, backtracking, restart,
coroutine, and transaction retry.

## Current measured boundary

`effect` is a graph fact; `world` models authority. There is no `condition` or
`continuation` fact family, and no list of available restarts.

**Crossed:**

- `law.effect` and `law.world` exist in C0.
- `async`, `exception`, `yield` are mentioned as research targets.

**Still missing:**

- `Continuation` as a semantic value: captures semantic future, resume count,
  escape, dynamic resources crossed, effect obligations.
- `Condition` as a semantic event with fact/effect payload.
- `restarts(condition)` = set of admissible recovery relations.
- Realization table:
  never invoked → erase;
  nonescaping once → direct branch;
  escaping once → movable frame;
  multiple invocations → persistent/copied continuation;
  only failure → exception/result branch;
  only generator → state-machine cursor.
- Compiler conditions as first-class events: `missing proof: nonalias(x,y)`
  with restarts `guard`, `profile`, `copy`, `generic`, `refuse`.

## Required order

1. Define `Continuation` and `Condition` descriptors in C0.
2. Add facts for capture count, escape, dynamic extent, effect obligations.
3. Implement `restarts(condition)` as a graph relation.
4. Derive exception/result, yield, async, generator, backtracking, restart from
   the same algebra.
5. Use the algebra for compiler diagnostics (conditions with restarts).

## Closure acceptance

Close when `return`, `exception`, `yield`, `async`, `generator`, `backtracking`,
`restart`, and `retry` are all realizations of one continuation/condition
algebra, and compiler conditions expose available restarts.
