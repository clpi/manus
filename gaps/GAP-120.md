# GAP-120 — File boundaries lack durable semantic concept identity

**Status:** OPEN · **Filed:** !2026-08-09T20:08:31Z
**Priority:** P1 · **Kind:** expressiveness_gap
**Filed by:** codex_semantic_normalization
**Files:** src/semantic_graph.zig,docs/spec/constitution.md

C0 law.file.one now requires each file to be the durable home of one semantic concept across ownership, docs, tests, transforms and generated projections. The live graph and MCP can inventory paths but do not yet attach or validate a durable concept identity, so utility buckets and unrelated declaration bundles cannot be rejected semantically. Implement from the persistent graph/manifest, not filename regexes; expose the same structured finding through compiler, LSP, MCP and generated docs.
