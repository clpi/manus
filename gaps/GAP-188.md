# GAP-188 — pattern / search / rewrite algebra

**Status:** OPEN · **Filed:** !2026-08-18T16:15:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818

Patterns are not regex strings or match statements. A pattern is an ordinary
semantic relation over subject, span, captures, solution cardinality, and an
update/replacement relation. This unifies regex, token matcher, parser
production, tree pattern, graph query, rewrite rule, lens, find/replace, and
routing predicate.

## Current measured boundary

Parsing and regex exist as separate subsystems. Patterns are not a first-class
semantic value.

**Crossed:**

- `lib/compiler/lexer.id` and `lib/compiler/parser.id` perform pattern-like work.
- `string.match`, `string.sub`, `string.find` are primitives.

**Still missing:**

- A pattern is an ORDINARY RELATION whose facts name subject, span/place, captures, solution cardinality, search direction, and update relation — no `Pattern` semantic kind.
- Pattern composition: sequence, alternation, recursion, capture, repetition,
  negation.
- `match(pattern)(subject)` with `captures` and `span` results.
- `replace(pattern)(subject)(update)` as a relation.
- Search variants: `first`, `all`, `count`, `has`.
- Parser, regex, tree pattern, graph query as realizations of the same algebra.

## Required order

1. Express patterns as relations with mode/cardinality/span/update facts (GAP-187); no `Pattern` semantic kind is defined.
2. Compose patterns by ordinary relations (sequence, alternation, recursion, capture, repetition, negation) — `delta.operators = 0`.
3. Implement `match` and `replace` as ordinary relations.
4. Provide realizations: literal/SIMD for fixed text, DFA for fixed regex,
   NFA for complex, parser automaton for grammar, DAG for tree, indexed query
   for graph.
5. Unify `string.match`, `string.sub`, `string.find`, `string.gsub`, `regex`.

## Closure acceptance

Close when `regex`, `find/replace`, `parser`, `tree pattern` and `graph query`
are all realizations of one pattern relation, and the user-level surface for
all of them is the same algebra.
