# GAP-188 — first-class pattern, search, and matched-place rewrite algebra

**Status:** OPEN · **Filed:** !2026-08-18T16:20:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/pattern.id, src/rewrite.id

Unify pattern matching, parsing, regex, tree matching, graph queries, lenses, and
in-place rewriting into a single first-class semantic `PatternRelation`. SNOBOL4
demonstrated that patterns as first-class values with success/failure, capture,
and matched-region replacement provide a far richer substrate than flat regex or
destructuring match statements.

## Current measured boundary

Pattern matching is split across AST match nodes, regex library wrappers, and
parser grammar rules without a unified semantic identity.

**Crossed:**

- Structural graph matching exists in the compiler mid-end.
- Token recognition in lexer is formal.

**Still missing:**

- `PatternRelation` entity: `(subject, cursor/span, captures, solution_cardinality, update_relation)`.
- Pattern composition operations: sequence, alternation, recursive self-reference, capture binding.
- Multi-representation realization:
  - Literal search -> `memchr` / SIMD vector search
  - Fixed regex -> Deterministic Finite Automaton (DFA)
  - Complex regex -> Nondeterministic Finite Automaton (NFA)
  - Grammar production -> Parser pushdown automaton
  - Tree pattern -> Decision DAG
  - Graph pattern -> Indexed relational join
  - Rewrite rule -> In-place matched region mutation

## Required order

1. Define `PatternRelation` in C0 specification.
2. Formalize pattern combinators and capture semantics.
3. Build the candidate realization mapper (DFA, NFA, SIMD, Decision DAG).
4. Unify compiler rewrite rules with user-level pattern replacement.
5. Prove zero overhead for statically known literal and regular patterns.

## Closure acceptance

Close when regexes, parser productions, and tree rewrites are all instances of
`PatternRelation` and compile to optimal specialized machine automata without
runtime interpreter overhead.
