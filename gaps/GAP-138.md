## 2026-08-10 settlement (IDOL ONE)

The source substrate is now a self-contained executed relation set, called
subject-first from a held source value. No `req`, no `std.*` call site, no
namespace authority, no module table.

- `examples/pass16_source_module_proof.id` was rewritten as the canonical
  substrate: `bytecursor`/`loc` descriptors plus the subject-first relations
  `at` (byte at position, in-bounds only), `len` (boundary), `iter` (advance),
  `loc` (location projection), `formatloc`. `main` walks `"a\nb\nc"` by subject
  (`c:at()`, `c:iter()`, `c:len()`), checks newline count, location projection
  and `formatloc`. It is build-wired as `pass16_m1_smoke_step`.
- `lib/compiler/source.id` was deleted: legacy fused constructor/module
  calls (`cursornew`/`cursorpeek`/`cursoradvance`/`cursoreof`/`cursorloc`),
  byte-0-at-EOF sentinel, and the `std.compiler.source` map entry. The
  `source = req "std.compiler.source"` line was removed from `lib/std.id` and
  the unused `source` bind from `scripts/test_lexer.id`.
- `scripts/test_std.id` was deleted: std-distribution scratch with no callers.

EOF/presence contract: `at` is a partial relation over the in-bounds prefix;
presence is the boundary fact `pos <= c:len()` (`len` is an admitted relation),
so EOF is never a byte value and a NUL byte can never be conflated with
absence. The stronger presence-face form — `at` returning a
`present | absent` cell so the absence is consumed as an explicit case — is
`vocabularyblocked` on the C backend: a union-of-record return from a
branchy function does not lower (`lua_Value tmp = lua_table_new_with_capacity`
at the construction site), in any declaration form. The C backend must lower
union returns via a generated physical case tag before the substrate can
return the presence case directly.

Residual debt: the proof path is pinned to a `.id` extension by `build.zig`
(`pass16_source_module_proof`, owned by codex-root-idol-admission-20260810).
Convert the file to canonical `.id` and repoint the build step when that path
is claimable. String literals also cannot carry a NUL byte today (`"\0"` emits
as the digit `0`), so the executable proof demonstrates the boundary contract
structurally rather than with an embedded-NUL source.
