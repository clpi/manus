# GAP-199 — encapsulated optimizer spaces

**Status:** OPEN · **Filed:** !2026-08-18T17:00:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/semantic_graph.zig, src/optimizer.id

Optimization search should run inside encapsulated computation spaces. A space
holds a candidate semantic state with unresolved choices. An optimizer can:

- clone
- refine
- measure
- commit
- discard

without mutating canonical semantics. This is a transactional optimizer search
universe, similar to Oz computation spaces.

## Current measured boundary

The optimizer currently mutates a shared graph. There is no transactional search
abstraction.

**Crossed:**

- `demand`, `realization`, and `candidate` are graph facts.
- `FRONTIER.md` records rung priority and search policy.

**Still missing:**

- A search space is a DERIVED WORLD (`@{ … }` injection) holding its candidate assumptions as facts, physically held as a copy-on-write graph incarnation — no `Space` semantic kind, no snapshot object.
- Choice facts with alternatives as world facts.
- clone = derived-world formation · refine = fact injection · measure = realization evidence under that world · commit = publish a witnessed equivalence/realization fact · discard = drop the temporary physical incarnation.
- Commit only when a cheaper, lawful realization is proven.
- Discard dominated or failed incarnations.

## Required order

1. Model clone as derived-world formation, refine as fact injection, measure as evidence evaluation under that world, commit as witnessed publication to the canonical graph, discard as dropping the physical incarnation — no `Space` or `choice` kinds.
2. Add graph-snapshot mechanism (copy-on-write or persistent data structure).
3. Implement choice creation and exploration.
4. Implement space measure and commit.
5. Show that a search can explore candidates without mutating canonical graph.

## Closure acceptance

Close when an optimization can clone the graph, explore a representation
alternative in a space, and commit the result only if it is lawful and cheaper.

## C0 alignment

Instance of the schema in `gaps/RESEARCH-SPINE.md`; `tools/node/dev/gapc0` fails
closed without it.

- **constitutional owners:** world (derived search world by injection) · realization (candidate facts) · witness (commit evidence) · provenance
- **kind delta:** 0
- **registry delta:** 0
- **source syntax delta:** 0
- **semantic invariant:** an Oz-like optimizer computation space is a derived world — conceptually `@original{ assumptions = candidate facts }` — scoping evaluation without mutating the caller world; commit publishes a witnessed equivalence/realization fact to the canonical graph and never a silent rewrite.
- **physical mechanism:** copy-on-write or persistent graph incarnation; measurement under the derived world; commit provenance.
- **prerequisites:** GAP-198.
- **foreign implication:** foreign search spaces (autotuners, agent explorations) are derived worlds whose outputs commit only as witnessed candidates.
- **world implication:** THE world reuse — speculative search without mutating canonical authority; world closure law (no parent fallback) bounds what a space can read.
- **projection implication:** injection is the only face; no `Space` syntax exists or is needed.
- **demand implication:** measure evaluates realization evidence under the demanded quotient.
- **realization implication:** transactional search over candidates with originals surviving for translation validation (GAP-178).
- **evidence:** one search that clones, explores a representation alternative, and commits only if lawful and cheaper; a discard that provably leaves the canonical graph untouched.
- **deletion witness:** `Space` objects, snapshot machinery as semantics, destructive optimizer mutation.
