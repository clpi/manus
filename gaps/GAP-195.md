# GAP-195 — context-indexed semantics and eduction

**Status:** OPEN · **Filed:** !2026-08-18T16:30:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, docs/context-indexed.md

Generalize `world` and `stage` into arbitrary semantic context dimensions.
A semantic identity then denotes:

    meaning(value, context)

where `context` has dimensions such as `time`, `stage`, `target`, `revision`,
`place`, `sample`, `precision`, `observer`, `configuration`.

Eduction is the execution model: the observer demands `V@C`, the graph
propagates that demand backward, computes only demanded coordinates, and
memoizes results. This unifies compile time, runtime, target specialization,
incremental compilation, simulation timesteps, GPU placement, probabilistic
samples, configuration variants, and precision modes.

## Current measured boundary

`world`, `stage`, `place`, and `demand` are separate fact families. They are
not yet a unified context index.

**Crossed:**

- `world` and `stage` are graph facts.
- `demand` drives optimization.

**Still missing:**

- Context as a first-class value/set of dimensions.
- `value@context` as the denotation of an identity.
- Eduction engine: demand `V@C`, derive dependent demands, compute, memoize.
- Context dimensions: time, stage, target, revision, place, sample, precision,
  observer, configuration.
- Specialization as partial determination of context.

## Required order

1. Define `context` and `context dimension` in C0.
2. Make `world`, `stage`, `target`, `place` dimensions of context.
3. Implement eduction: `query(id, context, quotient)` returns facts/realization.
4. Make compilation demand-driven: `artifact(main, arm64)` induces only the
   demanded semantic sub-graph.
5. Use context-indexed values for incremental, staged, and specialized builds.

## Closure acceptance

Close when `compile time`, `runtime`, `target`, `revision`, `place`, and
`precision` are all context dimensions of one value, and when computation is
performed by eduction rather than whole-program traversal.
