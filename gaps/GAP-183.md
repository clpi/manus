# GAP-183 — cross-law semantic fusion

**Status:** OPEN · **Filed:** !2026-08-18T15:40:00Z
**Priority:** P1 · **Kind:** research_gap
**Filed by:** devin-semantic-20260818
**Files:** docs/spec/constitution.md, docs/spec/law.md, src/foreign_law.id, src/wasm_ingest.id

Fuse subgraphs from distinct source laws (Idol, Lua, Wasm, C, SQL, WIT) into one
semantic subgraph and one realization. Boundaries are deleted when observations
permit; only retained where a foreign observation is provably required. This is
Idol’s largest unique performance opportunity.

## Current measured boundary

Individual foreign laws (Lua, Wasm, C) have bootstrap ingestion paths, but
production semantic construction and resolution remain host-owned (S0: executed
lexer boundary; parser and later stages host-owned; no compiler B). Cross-law
fusion is a research destination, not current infrastructure.

**Crossed:**

- Wasm, Lua, and C ingestion paths exist and publish facts under their own law; exact cross-law semantic ingestion authority is NOT established.
- `law.foreign` and `law.bridge` exist in C0.

**Still missing:**

- Shared semantic equivalence region across foreign laws.
- Representation/authority/observation proof for each boundary.
- Fusion of a `Python table → Wasm transform → C kernel → SQL aggregate` chain.
- Canonical principle: keep a boundary only if an observer can see it.
- Algorithmic reductions that span law boundaries.
- Explicit witnesses before any convergence: relation equivalence, observation compatibility, authority compatibility, effect compatibility, representation compatibility, failure behavior. Foreign identities never converge because names or shapes look equivalent.

## Required order

1. Emit foreign facts in the SAME graph fact format as native semantics; `origin` and `law` qualify them — no separate foreign fact format.
2. Add equivalence and representation-theorem proofs across law boundaries.
3. Build a cross-law optimizer that recognizes the same relation in different
   source laws.
4. Demonstrate deleting at least one adapter/copy/lift/lower chain.
5. Measure the saved copies/calls/allocations.

## Closure acceptance

Close when a program with multiple source laws can be lowered to one semantic
subgraph and one realization, and when every retained boundary is justified by
an explicit observation proof.

## C0 alignment

Instance of the schema in `gaps/RESEARCH-SPINE.md`; `tools/node/dev/gapc0` fails
closed without it.

- **constitutional owners:** origin · law (source law) · provenance · witness; convergence itself is GAP-178's witnessed equivalence relation
- **kind delta:** 0
- **registry delta:** 0
- **source syntax delta:** 0
- **semantic invariant:** a foreign source law determines how bytes are interpreted; a world determines semantic context and authority after recognition — worlds never switch grammar; foreign meaning is an exact identity in the shared graph until a witness permits convergence.
- **physical mechanism:** shared graph substrate; cross-origin optimizer consuming witnessed equivalence; boundary retirement in order — syntax → semantic adapter → call → representation → copy → runtime; language identity remains provenance forever.
- **prerequisites:** GAP-178, GAP-184.
- **foreign implication:** THE foreign GAP — `Python → Wasm → C → SQL` chains fused to one realization only under the six witnesses.
- **world implication:** authority compatibility is a witness condition, never implied by shape.
- **projection implication:** foreign projections enter the one projection mechanism with origin qualification.
- **demand implication:** observation compatibility is a witness condition — only a demanded observation can force a retained boundary.
- **realization implication:** adapter/copy/lift/lower chains deleted where all six witnesses hold; one semantic relation with direct, fused, vector, GPU, and closed-form realizations surviving side by side.
- **evidence:** one fused multi-law chain with saved copies/calls/allocations measured against the unfused baseline.
- **deletion witness:** per-boundary adapters and lift/lower glue.
