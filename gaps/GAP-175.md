| # | directive |

| 1 | **Still missing:** |

- A common `fact` lattice over each semantic value, not one lattice per
  analysis.
- Explicit `refine(domain, evidence)` for combining evidence from multiple
  provers (abstract interpretation, e-graph, SMT, symbolic execution,
  profiling, agent search).
- Reduced products: `range [0,255]` × `x ≡ 0 mod 16` → only 16 possible

  candidates.
- Provenance for every fact: axiom, source-law, proven, inferred-sound,
  guarded, profiled, sampled, heuristic.
- Status labels that distinguish epistemic unknown from semantic partiality
  (`not queried`, `queried but unknown`, `partially known`, `nondeterministic`,
  `fundamentally uncomputable`).

## Required order

1. Define the abstract interpretation infrastructure in C0 terms: concrete
   semantic domain `C`, abstract fact domain `A`, abstraction `C → A`,
   refinement `A × evidence → A`, ordering = "more precise knowledge."
2. Express every existing fact family as an instance of the substrate, with
   explicit transfer functions across the source-to-machine semantic graph.
3. Add dependency and provenance to every fact so `unknown` carries its
   epistemic cause and the cost to refine it.
4. Implement reduced products between the highest-value fact pairs and measure
   the realized search-space contraction.
5. Make SMT, e-graph, symbolic execution, and agent search clients of the
   substrate, returning evidence to the same fact graph rather than separate
   subsystems.
6. Use the substrate to drive a fixed-point compilation schedule: publish
   initial facts, apply semantic inference relations until demanded facts reach
   a fixed point, then materialize the requested realization.

## Required controls

- No new ad-hoc lattice or worklist for a new fact family.
- Every fact has a status and a provenance.
- `unknown` is never overloaded without its specific epistemic state.
- Fact families remain separate meanings but can lawfully refine one another.
- No single flat "god lattice"; explicit reductions and reduced products only.

## C0 alignment

| # | directive |

| 1 | Instance of the schema in `gaps/RESEARCH-SPINE.md`; `tools/node/dev/gapc0` fails closed without it. |

- **constitutional owners:** id (facts qualifying identities) · relation (transfer functions) · witness · provenance · trust
- **kind delta:** 0
- **registry delta:** 0
- **source syntax delta:** 0
- **semantic invariant:** every analysis is a fact family qualifying existing ids under one partial order; `refine(domain, evidence)` is an ordinary witnessed relation application; `unknown` carries its epistemic cause and its refinement cost.
- **physical mechanism:** one fixed-point scheduler (index/cache roles) shared by every fact family; reduced products are joins in the substrate.
- **prerequisites:** none — substrate root beside GAP-187.
- **foreign implication:** foreign analyses publish into the same fact families through origin/provenance; no foreign fact format.
- **world implication:** world facts are one refinable family; closed-world law unchanged.
- **projection implication:** none — fact discovery is ordinary graph projection.
- **demand implication:** demand is itself a refinable fact family.
- **realization implication:** reduced products delete candidate families before search begins (range × congruence collapsing a value to 16 possibilities deletes the general-code realization family) — search-space contraction, not faster codegen.
- **evidence:** measured search-space contraction from at least one reduced product, plus a census proving no analysis retains a private worklist/cache/invalidation model.
- **deletion witness:** per-analysis lattices, worklists, caches, and invalidation models.
