# GAP-170 — Exact observation model (OBSERVATION-MINIMUM)

**Status:** OPEN · **Priority:** P1 · **Kind:** language design / semantics
**Owner:** Cursor (canonicality / design authority) · consumers: Codex (graph), Poolside (realization)

## Obligation

Define the exact observation model: the behavior every realization must preserve.
Law: `docs/spec/law.md` §103 OBSERVATION-MINIMUM; C0 `law.observation.minimum`
(`why = law.physical.open`). A realization must preserve only what the program's
semantics actually make observable; everything else is free to change under
`law.physical.open`.

This is the single highest-leverage remaining language-design work. FTCFTW power
is proportional to how precisely Idol defines what is and is not observable —
**every accidental observable is a permanent optimization barrier**. The physical
realization space of GAP-169 is only as large as this model allows.

## Deepest framing (OBSERVATION-ONE / BOUNDARY-ONE)

`law.observation.one` (`docs/spec/law.md` §104) is deeper than OBSERVATION-MINIMUM:
a program *is* a set of required observable relationships among inputs, worlds,
effects, outcomes, and outputs — not a sequence of steps. If written intermediate
bindings/applications disappear entirely, that is ideal. This model must also fix:

- **Semantic vs physical time** — `A` happens-before `B` requires no wall-clock
  duration; execution duration and scheduling are not observable unless the
  program observes a clock/deadline world fact (reading a clock is an effect).
- **Allowed outcome sets** — concurrency, unordered iteration, and randomized
  algorithms admit a set of valid outcomes; the optimizer may realize one of them
  unless world/demand constrains it. Determinism/reproducibility are world demands.
- **World-dependent observability** — a security world may make timing, cache
  access, and addresses observable (constant-time/oblivious realization); an
  ordinary world does not. The observable set is a world fact, not a global constant.
- **`none` representation** — physical nonexistence is a first-class realization
  state; the default optimization question is whether some required observation
  depends on an entity's physical existence.
- **BOUNDARY-ONE** (`law.observation.one` folds it; §105) — representation is free
  except at irreversible boundaries (foreign ABI, file format, network protocol,
  shared memory, observable pointer, volatile/device, authority, debugger address);
  foreign representation has finite extent (exactly the foreign application) and
  never infects the whole program; serialization/parsing are projection/inverse
  projection under a descriptor; endian/alignment are boundary facts.

## What must be classified (observable vs realization)

For each behavior, decide: is it a preserved semantic observation, or a free
realization choice? Default conservative (observable) only where a proof is
absent; narrow later, never widen silently.

Presumptively **non-observable** (realization choices) unless a fact makes them
observable:

- allocation identity, address, and existence of a place;
- table/record/array physical layout (AoS/SoA/split/scalarized/frozen);
- iteration order over unordered collections;
- exact instruction schedule and micro-architectural timing;
- intermediate strings and temporaries in a fused pipeline;
- physical representation, width, and encoding of a value;
- device (CPU/GPU/NPU/core class) and storage tier;
- thread placement, memory tier, and page size;
- whether a pure result is recomputed, memoized, or precomputed.

Presumptively **observable** (must be preserved) unless proven otherwise:

- values and value relations demanded by the program;
- ordering the program's semantics actually fix (e.g. declared-ordered maps);
- observable effects, their authority, and their externally-visible order;
- error/trap semantics the program can catch or that escape a boundary;
- floating-point results **except** where a precision/error demand permits
  approximation (GAP-169 precision class);
- foreign-ABI-visible representation at a real boundary;
- concurrency observations at genuine sharing/atomicity points.

## Dependencies and interactions

- **Effects/authority** — observable effect ordering is fixed by the effect and
  world model, not by realization (`law.cost.explain`, `law.world.closed`).
- **Precision** — approximation is legal only when a descriptor/demand explicitly
  permits an error bound (GAP-169 § precision proportional to demand).
- **Ordering** — unordered table semantics free iteration order; declared order
  is observable. The line must be a graph fact, not source spelling.
- **Concurrency** — the memory/observation model at sharing points bounds
  transaction/optimistic-concurrency/lock-shape realization (GAP-169).

## Floor (2026-08-15) — NO LONGER BLOCKED AT S0

**The blocking sentence above stopped being true on 2026-08-15.** `src/place.zig`
is the entity an observation fact hangs on (§18's eleven facts, three-valued,
accesses at program points with loop-derived multiplicity) and `src/eqspace.zig`
is a consumer that deletes realization families from facts before cost is
consulted. `src/observation.zig` is the classification between them.

**MEASURED, at idol `2843fad3`, `--backend=direct`, Apple Silicon:**

- **The graph now carries 16 observation classes per place** — GAP-170's two
  lists above, nine presumptively non-observable and seven presumptively
  observable — each three-valued with `unknown` blocking, each naming the
  observers that could distinguish, the reason, and the producer. 35 unit tests.
- **A program that observes allocation identity gets a different answer.**
  `s = (1,2,3); t = (1,2,3); if s == t` answers **0**; `t = s; if s == t`
  answers **1**. Interning the two equal literals — the realization the
  `none` and zero-copy families take — flips 0 to 1, so allocation identity is
  observable *in this language* and not merely in principle. (This also closes
  `docs/observation.md` E12, which recorded `a == a` as broken for a table: it
  is broken in the vendored `bin/idol` and correct at `509497cf` onward.)
- **The block reaches the candidate set.** With identical `eqspace` facts, a
  place whose identity is captured admits strictly fewer realization families
  than one whose is not, and every casualty names the freedom, the class and
  the reason that deleted it.
- **The freedom that is available and not taken has a number: 71 of 73
  instructions.** A runtime-built 3-element place, summed to the answer, costs
  73 instructions of `main`; its lawful floor — the same observable behaviour
  with no place at all — is 2. The model classifies allocation identity, layout,
  schedule and width all NOT OBSERVED for that place and opens `existence`,
  `zero_copy`, `layout`, `width`, `schedule` and `memoization`. Nothing in the
  compiler consumes the fact. **97.3% of that program is an unasked question**,
  and `gate/observation.sh` (idol-native) ratchets it in both directions.

**What is still blocked, stated as refusals rather than gaps:**

- **No realization consumes the classification yet.** `admit()` composes with
  `eqspace.contract`, and `eqspace` is itself not wired into lowering. The
  measured 71 instructions are the size of that gap, not a claim about it.
- **Every check in the model is SINGLE-TRACE.** In a world demanding
  determinism, noninterference, serializability or linearizability the model
  authorizes *nothing* and returns `blocked_hyperproperty` — a distinct verdict
  from "observed", so a reader is never told the wrong instrument succeeded.
  GAP-171's equivalence checker is where that stops being a refusal.
- **Concurrency, foreign-boundary and device classes are classified but not
  censused.** They have producers and rules; no program on this surface
  exercises them, so no incidence number is claimed.

## Deletion conditions — status 2026-08-15

1. **MET.** `src/observation.zig` `classifyAll(world, evidence, obligations,
   subject)` produces a `Report` of all 16 classes for a subject that is a
   `place` id, an `application` program point, or the whole program. Every
   `Fact` carries `{observed: yes|no|unknown, by: ObserverSet, reason,
   provenance{producer, authority, subject}}`. A `no` is only ever issued with
   `authority = .proof`; the conservative default can only issue `unknown` or
   `yes`. Unit test: *every classification carries provenance*.
2. **MET IN THE GATE, NOT YET IN LOWERING.** `gatingClasses(freedom)` maps each
   of the 11 freedoms (GAP-169's seven plus existence, schedule, width,
   placement) to the classes that must ALL read a proven non-observation, and
   `permits()` takes a report and a freedom and *has no cost parameter* — the
   same signature-level enforcement `eqspace.contract` has. There is no path
   from a heuristic to a permission. What is NOT met: no backend consults it.
3. **MET, AND BUILT FIRST.** Five positive controls, three of them on real
   parsed programs rather than hand-set flags: identity comparison blocks
   `existence` and `zero_copy`; an enumeration reaching an effect blocks
   `order`; a positional read blocks `order` through `fixed_ordering` *and
   nothing else*; the block deletes `bitset` and `hashed` from the candidate
   set while `scan` survives. `gate/observation.sh` proves the controls bite by
   perturbing the model five ways and requiring each to be caught: "always not
   observed" (22 of 35 tests fail), "always observed" (19), world-blind (5),
   `unknown` reads as `no` (5), order detector disarmed (3).
4. **PARTIALLY MET, WITH THE ONE SURVIVING BLOCKER NAMED.** On the measured
   probe exactly one lawful realization is blocked, and for a stated semantic
   reason rather than an accident: `order` is closed because the program reads
   `s(j + 1)`, so index-to-value is ordering the semantics fix. No accidental
   observable survives on that program. The audit is not corpus-wide — HPLS §91
   asks for a continuous hunt and this is one probe — and two accidental
   observables found today by the sibling lane remain routed rather than fixed:
   `native_backend.emitTrapAbort` open-codes `kill(getpid(), SIGABRT)` and
   silently drops pre-trap stdout, and the io constructor's arrival observation
   is linked by four ingress symbols that have no relation to stdout arrival.

## Floor (2026-09-06) — the effect fact stopped being issued as a proof

Deletion condition 2 asks that every realization freedom be gated by a **proven**
non-observation, "not by a heuristic". The effect detection in
`src/observation.zig` was a heuristic *read as a proof*, and the fail-open
reached the freedoms this gap exists to open.

`isEffectName` is a sixteen-name spelling list. Read as a positive recognizer it
is honest. Read as a permission it is not, because the question it answers is
whether a NAME IS ON IT, never whether a relation observes anything. The walk
read `false` as "pure": `analyze` published `has_effect = .no` for the region,
`classify(.effect_order)` returned `free(..., .observation_walk, ...)` — and
`free` sets `authority = .proof` — and `permits(report, .memoization)` returned
`.permitted`.

**MEASURED, on the vocabulary `CLAUDE.md` teaches as canonical** (WORLD-ONE:
prefer `stdin:read()`, `args(1)`, `env(...)` over `io.*` / `os.*` namespace
teaching). None of those names is on the list, so

```id
main: i64 = ()
    s = (1, 2, 3)
    x = stdin:read()
    s(1) + x & 255
```

classified `effect_order` NOT OBSERVED with `authority = .proof` and permitted
`memoization` — for a region that consumes its input. Memoizing that region
skips the read. The same hole ran in the order dimension: `walkLoop` published
`order_reaches_effect = false` for a loop body applying a relation it cannot see
through, so `iteration_order` could read free while the loop wrote its
enumeration out. Whether the model saw a program's effects at all was decided by
whether its author spelled them `print` or `stdin:read`.

**THE REPAIR IS THE CLASS, NOT THE SPECIMEN.** Adding `stdin`, `read`, `args`
and `env` to the list restores the identical defect at the next canonical face.
The walk's effect knowledge is three-valued instead, and the list keeps only the
job it can do:

- a name ON the list marks `.yes` — a proof of an effect is still a proof;
- an applied relation NOT recognized marks `.unknown` (`markEffectUnknown`);
- `.no` now means "this region applied no relation at all", which the walk
  really does establish.

`Evidence.order_reaches_effect` becomes `Tri` for the same reason, and
`iteration_order` and `fixed_ordering` grew the `unknown` arm `Tri` requires.
This is N2's own rule applied to the effect fact: a shape the walk does not see
through raises the region rather than passing it.

**A second fail-open in the same walk, closed with it.** `clock()` produced
`WorldFact.clock_read` and `t:now()` did not, so duration was observable through
one spelling of one relation and free through the other, and `permits(.schedule)`
read `permitted` for a program that reads a clock subject-first. A world fact is
a property of the relation, never of the face it was written with.

**Diagnostic and controls — five permanent tests in `src/observation.zig`:**

| test | asserts |
|---|---|
| DIAGNOSTIC — a region that reads input proves no effect-freedom | `complete`, `has_effect = unknown`, `effect_order = unknown`, `recompute_vs_memoize = unknown`, `permits(.memoization) = blocked_unknown` |
| an unclassified relation in a loop leaves ENUMERATION order unknown | `complete`, `order_reaches_effect = unknown`, `iteration_order = unknown`, `permits(.order) = blocked_unknown` |
| CONTROL — a region that applies no relation still PROVES effect-freedom | `has_effect = no`, `effect_order = no` carrying `authority = proof` |
| CONTROL — a recognized effect still proves `.yes`, not `unknown` | `print(s(1))` gives `effect_order = yes`, `recompute_vs_memoize = yes` |
| a clock is a clock in either face, so the SCHEDULE freedom shuts in both | `wall:now()` gives `world.clock_read`, `instruction_schedule = yes` by `duration_observed`, `permits(.schedule) = blocked_observed` |

The two diagnostics assert `complete` FIRST, so neither can pass because the walk
stopped seeing the program rather than because it refused the effect. The two
CONTROLs are the over-block controls and the green run discharges them: a
`markEffectUnknown` that fired unconditionally fails the third row, and one that
degraded a recognized effect fails the fourth.

**FALSIFICATION, run rather than asserted.** `markEffectUnknown` reverted to
`_ = ctx;` — the fail-open restored, nothing else touched — and re-run over the
same 2146-test set: **25 failures became 27**, the two added being exactly
`DIAGNOSTIC — a region that reads input proves no effect-freedom` and
`an unclassified relation in a loop leaves ENUMERATION order unknown`. Both
CONTROLs still passed under the perturbation, which is what makes them controls
rather than restatements of the new behaviour.

**Aggregate, stated with its red.** `tools/node/dev/idol-lock -- zig build
unit-test` on the landed tree: **2056 of 2147 pass, 66 skipped, 25 fail**. All 40
`observation.*` tests pass. The 25 are `parser.*` (`src/parser.zig` live-claimed
by GAP-145), `codegen.*` (live-claimed by GAP-239) and `dnir_lower.*`; none of
those modules imports `observation.zig`, and the failure count is 25 before this
change, 25 with its four tests, and 25 with its five — the perturbation is the
only thing that moves it.

**WHAT THIS DOES NOT CLOSE.** Deletion condition 2 stands open for the reason the
2026-08-15 floor gave: **no backend consults `permits`**. This lane could not
change that — `src/dnir_lower.zig`, `src/codegen.zig`, `src/native_ir.zig`,
`src/native_bootstrap.zig` and `src/main.zig` were live-claimed by GAP-239
throughout. The exact consumer is named for whoever holds them:
`dnir_lower.placeFold` already takes the `existence` freedom, and it takes it
from `place.residencyRefusal` alone. That refusal never asks whether allocation
identity is observed; it is fail-closed today only because a captured identity
happens to drive `escape` to `unknown` through a different producer. Routing it
through `observation.permits(report, .existence)` — the shape GAP-185's
`collectStaticPlaces` -> `graph.static_places` -> `dnir_lower` already landed for
authority facts — is the next bounded transfer.

Two further refusals this floor does not repair, both recorded rather than
guessed at:

- **`Position.boundary_arg` is unreachable.** No walk arm produces it, so
  `Evidence.crosses_boundary` is always `false` from `analyze`, and
  `foreign_representation` therefore issues a `.proof` non-observation from
  evidence never gathered. That is sound only if no source face on this surface
  can cross a foreign boundary — which is a claim about the surface, not a
  proof the walk performed. Tightening it closes freedoms and needs the E1-E12
  enumeration in hand.
- **`analyze` walks only the FIRST `func_decl`.** A module with a second
  relation is classified from a region whose siblings were never seen. It is
  fail-closed today only because `place.analyzeFunction` censuses that same one
  function, so no unseen place has a row to be permitted — safety by coincidence
  of two producers, not by a rule either one states.

## Floor (2026-09-06) — the boundary fact stopped being issued as a proof

The first refusal above is closed. `Evidence.crosses_boundary` was `bool`,
default `false`, and no walk arm produces `boundary_arg`, so every walked
region published a proven boundary non-observation and `foreign_representation`
read `free` with `authority = .proof` — the same fail-open as the effect fact,
one floor earlier. `stdin:read()` on a place-bearing region permitted `layout`
and `width` across a boundary the walk never examined.

The repair mirrors the effect repair. `crosses_boundary` is `Tri`, default
`.unknown`; `markBoundaryUnknown` fires at exactly the three sites
`markEffectUnknown` fires (unrecognized call, computed callee, unrecognized
method); region settle is `raise(.no, any_boundary)`, so `.no` still means "no
crossable application", which the walk establishes. All five boundary
consumers (`allocation_identity`, `physical_layout`, `representation_width`,
`device_and_tier`, `foreign_representation`) take `.yes` as observed and
`.unknown` as blocking. Element reads (`s(i)`, `s[i]`) return before either
mark, so the measured probe keeps its open freedoms.

Tests, all in `src/observation.zig`: DIAGNOSTIC (walked `stdin:read()` region:
`complete`, `crosses_boundary = unknown`, `foreign_representation = unknown`,

neutered to `_ = ctx` re-run over the same set — exactly one added failure,

## Deletion conditions

1. The graph carries an explicit observation classification for each behavior
   class above, producible per application/place, with provenance.
2. Every GAP-169 realization freedom (layout, order, device, tier, precision,
   memoization, zero-copy) is gated by a proven non-observation fact from this
   model, not by a heuristic.
3. A positive control: a program that *does* observe one of the presumptively
   non-observable behaviors (e.g. captures allocation identity or fixes order)
   blocks the corresponding realization, and the gate proves it.
4. No accidental observable remains that blocks a lawful realization without a
   named semantic reason.

## Observation + obligation + hyperproperties (2026-08-13)

The observation model is one side of semantics; **obligation** is the co-equal
other (`docs/spec/law.md` §109 OBLIGATION-ONE, C0 `law.obligation.one`). The
graph fact set this GAP must carry therefore includes, per application/place:

- **positive obligations** — respond, commit durable state, deadline, ordering,
  release resource, availability-under-fault, authority boundary;
- **negative obligations** — no network / allocation / secret-dependent timing /
  write-after-cancel / duplicate external effect / persistent state / data
  leaving a region (the strongest optimization enablers: a proven `cannot`
  deletes whole mechanisms);
- **temporal** — `eventually A`, `A until B`, `never C after D`, `within
  deadline`, `at most once`; **safety vs liveness** kept distinct;
- **progress model** (wait/lock/obstruction-free, eventual, best-effort) and
  **fairness** observability as world facts (never globally promised);
- **causality** (`B because of A`) distinct from order; **counterfactual** facts
  for speculation/rollback/deopt; **noninterference** as a relation between
  executions.

Critically, equivalence is **not** single-trace: determinism, noninterference,
serializability, linearizability, and observational consistency are
**hyperproperties** over *sets* of executions. The equivalence checker (GAP-171)
must preserve demanded hyperproperties, not only per-trace observations — a
single-trace oracle is an unsound acceptance criterion for these worlds.
