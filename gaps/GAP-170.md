| section |
|---|---|
| Deepest framing (OBSERVATION-ONE / BOUNDARY-ONE) |

| # | directive |
|---|---|
| 1 | `law.observation.one` (`docs/spec/law.md` §104) is deeper than OBSERVATION-MINIMUM: a program *is* a set of required observable relationships among inputs, worlds, effects, outcomes, and outputs — not a sequence of steps. |
| 2 | If written intermediate bindings/applications disappear entirely, that is ideal. |
| 3 | This model must also fix: |

| # | directive |
|---|---|
| 1 | **Semantic vs physical time** — `A` happens-before `B` requires no wall-clock duration; execution duration and scheduling are not observable unless the program observes a clock/deadline world fact (reading a clock is an effect). |
| 2 | **Allowed outcome sets** — concurrency, unordered iteration, and randomized algorithms admit a set of valid outcomes; the optimizer may realize one of them unless world/demand constrains it. Determinism/reproducibility are world demands. |
| 3 | **World-dependent observability** — a security world may make timing, cache access, and addresses observable (constant-time/oblivious realization); an ordinary world does not. The observable set is a world fact, not a global constant. |
| 4 | **`none` representation** — physical nonexistence is a first-class realization state; the default optimization question is whether some required observation depends on an entity's physical existence. |
| 5 | **BOUNDARY-ONE** (`law.observation.one` folds it; §105) — representation is free except at irreversible boundaries (foreign ABI, file format, network protocol, shared memory, observable pointer, volatile/device, authority, debugger address); foreign representation has finite extent (exactly the foreign application) and never infects the whole program; serialization/parsing are projection/inverse projection under a descriptor; endian/alignment are boundary facts. |
