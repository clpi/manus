# GAP-071 — Pass 116's new deny rows, measured on the day they became law

**Status:** OPEN (measured baseline) · **Filed:** 2026-08-08
**Law:** Pass 116 §6d SELF-ZERO + RECOGNITION · Pass 112 §7 AUDIT v4

Pass 116 adds rows to the deny list. A deny list is only pressure if its rows
can reach zero, and it is only honest if the starting distance is recorded. This
is that record, so nobody reads the regenerated `CLAUDE.md` §1 as a description
of a property the repository already has.

## SELF-ZERO

> *"THERE IS NO SELF: `.x` reads the subject's fields · leading `:name()`
> invokes on it · a void body in chain position RETURNS it · bare `.` is its
> value · `...` spreads it. **A parameter named `self` = audit finding**;
> parameter lists count true arguments only."*

Measured over tracked `.duo`:

```
29 files declare a parameter named `self`
```

Not a stylistic sweep. The rule says parameter lists count TRUE ARGUMENTS ONLY,
so removing `self` changes each function's arity — which changes native
signature promotion, the `f64AbiParamSlots` count, record explosion, and every
call site. Several of tonight's miscompilations lived in exactly that machinery
(gap[056] argument classification, gap[058] register files). This is a real
migration with a real blast radius, not a rename.

## RECOGNITION

> *"no `std.mem`/`fmt`/`math` — pure ops are value edges (`x:abs()`,
> `s:copy()`); worlds are the only capability namespaces."*

```
std.math.   16 files
std.mem.     1 file
std.fmt.     1 file
```

`std.math` is the substantive one. The replacement is not a rename either: a
pure op becomes a VALUE EDGE on a descriptor (`x:abs()`), which means the edge
has to exist on every numeric descriptor it is called for, and `RECOGNITION`
also says idiom recognition lowers to intrinsics UNDER WITNESS — so the target
form depends on machinery (`why(realization)`) that does not exist yet
(gap[064] records `why` as an undeclared function).

Sequencing consequence: the `std.math` row cannot reach zero before the witness
surface exists. Turning it on now would force 16 files into a spelling with no
way to prove its lowering.

## Why this file exists rather than a silent deny row

Tonight produced a repeated pattern worth not repeating: a rule is written, the
audit lists it, and the number behind it is never measured — so the list reads
as satisfied. It happened with `std@{ ambient = false }` (gap[061]: assumed
clean, measured 53 of 257 modules) and with the `rand` class inside that same
scan (assumed zero, actually 50 sites — the probe was broken and the file said
so and shipped anyway).

The rows above are in `CLAUDE.md` §1 as of this commit. They are **not** at zero.

## Order of work, argued

1. **`std.mem` and `std.fmt`** — one file each. Cheap, and they prove the
   value-edge form on a small surface before it is asked to carry 16 files.
2. **`self`** — mechanical per file, but arity-changing, so it wants the ABI
   gates green throughout and should go a few files at a time with
   `abi-matrix` and the corpus differential run between batches. Do NOT batch
   it with anything else; if a differential reddens, the cause must be
   unambiguous.
3. **`std.math`** — blocked on `why(realization)` and the intrinsic-recognition
   path. Record the blocker rather than forcing the spelling.

## Falsifier

If `CLAUDE.md` §1 still lists these rows in a month and this file still reads
29 / 16 / 1 / 1, the deny list gained rows it cannot enforce, and the audit is
describing an aspiration.
