# ChatGPT Audit: Idol Business Positioning (2026-09-13)

## Core Shift
From 'a language that produces better programs' to 'a language that makes changing and operating software substantially safer, cheaper, and less dependent on human supervision.'

## Positioning
Idol lets people and agents change useful software without repeatedly reconstructing what it means, what it is allowed to do, what has already happened, and why it is still safe to run.

## Eight Gaps
A. Specification discrimination (not just generation)
B. Stateful upgrades (code + state + effects transition)
C. Permission governs actual action, not plan
D. Precise 'did it happen?' under partial failure
E. Fact lifetimes, revocation, deletion
F. Model behavior contracts (constraints vs quality vs unresolved)
G. Safe personalization (constrained change, not fork)
H. Coordination from invariants (not deployment habits)

## Unifying Opportunity
Reusable assurance: cost of accepting change follows invalidated obligations, not app size.

## Challenges to Idol Assumptions
- One semantic system != one global truth owner
- Fewer lines != less work
- Model should not get more context by default
- Self-hosting != security proof
- Mission-critical != maximum static proof
- Organization must not forget how system works
- Indispensable != impossible to leave

## Commercial Demonstration
Agent safely changes running app while preserving state, permissions, obligations.
Measure: faster accepted change, lower operational burden, better execution, less maintained complexity, durable usefulness.
