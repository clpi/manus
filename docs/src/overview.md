# Semantic Architecture

Idsem has one persistent semantic vocabulary from source or foreign import to
the graph. Demand removes unused physical work. Realization chooses among
lawful physical forms. Machine operations and object bytes remain projections
with causal provenance; they do not rename meaning.

```text
source or import
    -> semantic graph
    -> demand
    -> realization
    -> machine
```

## Identity and facts

Within one graph incarnation, the exact graph entity or its owner-defined dense
coordinate is identity. Names, paths, suffixes, delimiters, candidate addresses,
hashes, fingerprints, opcodes, ABI slots, and instructions cannot select
meaning. Cross-incarnation continuity requires an explicit graph-owned
correspondence fact.

Unknown, absent, empty, zero, and false are distinct. Applications preserve
relation, subject when present, argument and result packs, slot correspondence,
values, descriptors, constants, worlds, effects, demand, provenance, and
witnesses where known. Distinct occurrences remain distinct even when they
apply one relation.

## Maximum information, minimum ceremony

Canonical source uses the smallest face that exposes the strongest fact already
known. Subject-first application beats a namespace call when the subject is
possessed. Named projection beats a computed string key when identity is
static. An expected descriptor beats redundant descriptor spelling. Direct
composition beats a single-consumer bridge.

Boolean helpers are not a default semantic model. A case, descriptor fact,
world fact, transition, refinement, demand, shape, effect, or identity remains
that richer fact rather than becoming `has`, `is`, `can`, `exists`, or a
sentinel comparison. Unknown and absence never collapse to false. Missing
vocabulary is a blocker, not permission to invent a predicate.

## Root-zero distribution

The standard distribution contributes implementations, descriptors, laws, and
foreign mappings without a semantic namespace root. `std` is migration
distribution; `std.script` is frozen historical architecture. No replacement
universal root is admitted. Tooling discovers applicable relations from a
subject and exact graph facts. Sealed programs pay no runtime registry,
reflection, package traversal, or dynamic-dispatch cost for implementation
discovery.

## Physical freedom

A value is not a place. A binding is not storage. A pack is not an allocation.
A structured value is not a record layout. Computed indexing is not a hash
table. Numeric width and format remain observable descriptor facts where laws
require them and realization choices where they do not.

The performance target is maximum semantic knowledge with minimum physical
state. FTCFTW evidence reports the exact exercised path and separately accounts
for runtime, compile work, startup, memory, artifact and support footprint, and
incremental work. Wasm additionally accounts for decode/import, instantiate,
and end-to-end latency.

## Clean-room state

Every tracked file is training material. Project-owned `.duo`, current-facing
historical branding, stale examples, duplicated grammar tables, namespace
authority, sentinel cases, predicate bridges, static bracket misuse, and new
host semantic ownership all descend to zero. Git is the historical archive.
Until the generated censuses and search adversaries reach zero, the repository
must report clean-room readiness as blocked.
