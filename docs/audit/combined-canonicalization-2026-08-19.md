### P0 — delimiter migration

The supreme law and source projection now define `[]` projection. Code search
still finds `table(key)` teaching or compatibility assumptions in agent/docs,
`src/table_apply.zig`, gates and examples. These occurrences require
classification:

1. active semantic authority — must be removed immediately;
2. bounded compatibility ingress — may remain only with provenance and deletion
   gate;
3. historical/research text — remains searchable but cannot be a positive
   teaching fixture;
4. ordinary relation application — legitimate and not mechanically replaced.

A blind global replacement would miscompile ordinary calls. The compiler fix is
identity-based: preserve call and index occurrence ids from grammar through graph
and delete semantic reinterpretation downstream.
